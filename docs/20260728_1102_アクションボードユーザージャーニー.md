# アクションボード ユーザージャーニー

## 概要

アクションボードは、チームみらいの支持者がミッション（応援活動）を通じてXPを獲得し、レベルアップ・バッジ獲得・ランキング上位を目指すゲーミフィケーション型の政治参加プラットフォームである。

本ドキュメントでは、ユーザーが初めてアクションボードに触れてから定着・貢献するまでのジャーニーを7つのフェーズに分けて記述する。

---

## フェーズ1: 認知・流入

### タッチポイント
- SNS（X、LINE、TikTok等）でのチームみらい関連投稿
- リファラルリンク（`?ref=CODE`）経由の共有
- キャンペーンQRコード（`?cv=CODE`）経由の流入（街頭活動・イベント等）
- 既存ユーザーのミッション達成シェア投稿（OGP画像付き）

### ユーザーの行動
1. リンクをクリックしてトップページ (`/`) にアクセス
2. ヒーローセクションで「テクノロジーで政治をかえる。あなたと一緒に未来をつくる。」というメッセージを見る
3. 街並みのイラストとチームみらいのロゴが表示される

### 画面構成（未ログイン時トップページ）
- ヒーローセクション: ロゴ + キャッチコピー + 「アクションボードに登録する」ボタン + 「アクションボードとは？」リンク
- メトリクスセクション: チームみらいの活動状況（全体の登録者数・アクション数等）
- アクティビティセクション: 他ユーザーのリアルタイム活動タイムライン
- ランキングセクション: アクションリーダーランキング
- フィーチャードミッション: 注目ミッション（2倍XP）
- カテゴリ別ミッション一覧

### ユーザーの心理
- 「何をするサイトだろう？」→ 他ユーザーの活動やランキングが見えることで活気を感じる
- 「自分にもできるかな？」→ 「アクションボードとは？」で詳細を知りたくなる

## フェーズ2: オンボーディング（理解）

### 「アクションボードとは？」の体験

ヒーローセクションの「アクションボードとは？」リンクをクリックすると、インタラクティブなチュートリアルモーダルが起動する。

#### ステップ1: ウェルカム画面
- アクションボードのロゴが表示される

#### ステップ2: アクション仙人の登場
> 「ここは、アクションボード。チームみらいを応援する者たちが集いし場所。わしは、このアクションボードの主、アクション仙人じゃ。」

#### ステップ3: 機能紹介
> 「このアプリではの、チラシ配り、イベント手伝い、ポスター貼り… あらゆる『応援のカタチ』を、気軽に、楽しく、こなせるようになっとる。」

#### ステップ4: 安心感の提供
> 「何をすればええか分からん？心配いらん。ちょいとした気軽なアクションも揃えとるから、初めてでも心配いらんぞい。」

#### ステップ5: 最初のミッション導入
> 「ではさっそく、初めてのミッションじゃぞ。まずは、チームみらいの公式サイトを見て、わしらの活動について学ぶんじゃ。」

#### ステップ6: 模擬ミッション体験
- 「チームみらい公式サイトを見てみよう！」のミッションカードが表示される
- ボタンを押すだけで自動的にミッションクリアとなる体験

#### ステップ7: 完了・動機づけ
> 「うむ、上出来じゃ！実際のミッションでは、提出すると経験値がもらえて、レベルアップもできるぞい。さあ、アクションボードでみらいを切り開くのじゃ！」

### ユーザーの心理
- アクション仙人という親しみやすいキャラクターにより敷居が下がる
- 模擬ミッションで「簡単にできる」ことを実感する
- XP・レベルアップの仕組みを理解し、ゲーム性に興味を持つ

## フェーズ3: 登録

### 登録フロー（2段階）

#### ステップ1: 同意フェーズ (`/sign-up`)
1. 生年月日を入力（18歳以上の確認）
2. 利用規約・プライバシーポリシーに同意

#### ステップ2: ログイン方法の選択
2つの選択肢が提示される:

**A. LINE ログイン（推奨・メイン導線）**
1. LINEログインボタンをタップ
2. LINE OAuth認証画面へリダイレクト
3. 認証完了後 `/auth/line-callback` でコールバック処理
4. ユーザーレコード作成 → `/settings/profile?new=true` へリダイレクト

**B. メール/パスワード登録**
1. `/sign-up-email` でメールアドレスとパスワードを入力
2. 確認メール送信 → `/sign-up-success` で「メールを確認してください」表示
3. メール内リンクからアカウント有効化
4. 初回ログイン時 → `/settings/profile?new=true` へリダイレクト

#### 裏側の処理
- リファラルコード（`?ref=`）がある場合: 紹介者にXPとアチーブメントが付与される
- キャンペーンコード（`?cv=`）がある場合: アトリビューション情報が保存される
- ユーザーレベルの初期化（Lv.1）

### プロフィール設定 (`/settings/profile?new=true`)

新規ユーザーは必ずこの画面に誘導される（ホームページアクセス時にプロフィール未設定なら自動リダイレクト）。

| 項目 | 必須 | 説明 |
|------|------|------|
| アバター | - | 画像アップロード |
| ニックネーム | 必須 | 表示名 |
| 生年月日 | 必須 | 18歳以上（登録時に入力済みの場合はプリセット） |
| 都道府県 | 必須 | 所在地（都道府県対抗にも使用） |
| 郵便番号 | 必須 | 7桁 |
| X（Twitter）ユーザー名 | - | SNS連携 |

### ユーザーの心理
- LINE連携で手軽に始められる安心感
- プロフィール設定項目が少なく、すぐに始められる
- 都道府県の入力で「地域の仲間」意識が芽生える

## フェーズ4: 初回ミッション達成（アハモーメント）

### トップページ（ログイン後）の変化
- ヒーローセクションが **プロフィールカード** に変わる
  - アバター、ニックネーム、Lv.1、都道府県、XP、進捗バー
- 都道府県対抗ランキングカードが表示される
- ミッション一覧で達成状況が可視化される

### 最初のミッション達成フロー

#### 1. ミッション選択
トップページのカテゴリ別ミッション一覧から、難易度の低いミッション（★1）を選択。

推奨される初回ミッション例:
- 「チームみらい公式サイトを見てみよう！」（LINK_ACCESS型 = ボタンを押すだけ）
- 「公式Xアカウントをフォローしよう」（LINK型 = URLを提出）

#### 2. ミッション詳細ページ (`/missions/[slug]`)
- ミッションの説明、難易度（★表示）、獲得XP
- アーティファクト提出フォーム（ミッションの種類に応じたUI）
- そのミッションのランキング
- 関連ミッション

#### 3. アーティファクト提出
ミッションの種類に応じた提出方法:

| 提出タイプ | ユーザー操作 |
|-----------|------------|
| LINK_ACCESS | ボタンをクリック（自動完了） |
| LINK | URLを入力して提出 |
| TEXT | テキストを入力して提出 |
| IMAGE | 画像をアップロード |
| IMAGE_WITH_GEOLOCATION | 位置情報付き画像をアップロード |
| QUIZ | クイズに回答 |
| REFERRAL | リファラルURLをコピーして共有 |
| POSTER | 地図上でポスター設置場所を選択 |
| POSTING | 地図上でチラシ配布エリアを記録 |
| NONE | 提出不要（自動完了） |

#### 4. ミッション完了ダイアログ
提出成功後、お祝いダイアログが表示される:
- 「おめでとうございます！」メッセージ
- OGP画像（動的生成）
- SNSシェアボタン（X、Facebook、LINE、URLコピー）

#### 5. XP獲得とレベルアップ
- ミッション難易度に応じたXPが付与される
- フィーチャードミッションは2倍XP
- レベルアップ閾値に達した場合、次回ホームアクセス時にレベルアップ通知が表示される

### ユーザーの心理
- 初回ミッションの手軽さに「これなら続けられる」と感じる
- XP獲得とレベルアップの即時フィードバックが達成感を生む
- シェア機能で友人に自慢したくなる → 新規ユーザー流入の起点になる

## フェーズ5: 習慣化・エンゲージメント深化

### 日常的な利用パターン

#### パターンA: SNSミッション（毎日〜数日ごと）
1. トップページでカテゴリ「シェアして広めよう」や「いいね！で応援」を確認
2. 公式投稿のリポスト、動画の視聴・いいね等の軽量ミッションを実行
3. XPを積み上げてレベルアップを目指す

#### パターンB: コンテンツ学習ミッション
1. 「チームみらいを学ぼう」「政策を深掘りしよう」カテゴリのミッション
2. マニフェスト読了、クイズ回答等
3. 知識が深まると同時にXP獲得

#### パターンC: 地域活動ミッション
1. ポスター貼り（`/map/poster`）: 地図上で掲示板の場所を確認し、ポスター設置を報告
2. チラシ配り（`/map/posting`）: イベントごとに配布エリアを地図上で記録
3. 位置情報付き画像で証拠提出

#### パターンD: クリエイター向けミッション
1. YouTube動画作成（`/settings/youtube` でアカウント連携）
2. TikTok動画作成（`/settings/tiktok` でアカウント連携）
3. 動画の再生数・いいね数がダッシュボード（`/youtube_stats`, `/tiktok_stats`）で可視化

### 成長の実感

#### レベルアップ通知
- ホームページアクセス時にレベルアップダイアログが表示される
- 新しいレベル番号とプロフィールカードの更新

#### バッジ獲得通知
- 特定条件を達成するとバッジが付与される
- ホームページアクセス時にバッジ獲得ダイアログが表示される
- プロフィールにバッジが表示される

#### ランキング確認
- 総合ランキング (`/ranking`): 日次・週次・月次・全期間で切り替え
- ミッション別ランキング (`/ranking/ranking-mission`): 特定ミッションでの順位
- 都道府県別ランキング (`/ranking/ranking-prefecture`): 地域内での順位
- 都道府県対抗 (`/prefecture-team`): 人口あたりXPで都道府県を比較

### ユーザーの心理
- レベル・バッジ・ランキングの3軸で継続モチベーションが維持される
- 「次のレベルまであと少し」という進捗バーが行動を促す
- 都道府県対抗で地域への帰属意識と競争心が刺激される

## フェーズ6: コミュニティ参加・貢献

### ソーシャル機能

#### ミッション達成のシェア
1. ミッション完了時にSNSシェアダイアログが表示される
2. OGP画像付きの投稿でフォロワーにアピール
3. シェアされたリンクから新規ユーザーが流入 → リファラルXP獲得

#### アクティビティタイムライン (`/activities`)
- 全ユーザーのミッション達成がリアルタイムで表示される
- 「みんなも頑張っている」という一体感
- 他ユーザーのプロフィールページ (`/users/[id]`) で活動を閲覧可能

#### リファラル（友人招待）
1. リファラル用ミッションから自分のリファラルURLを取得
2. SNS・LINE等で友人に共有
3. 友人が登録すると紹介者にXPが付与される

### 地域活動への参加

#### ポスター活動
- 公設掲示板マップ (`/map/poster`): 選挙区ごとの掲示板位置を地図で確認
- 民有地ポスター (`/map/poster-residential`): 個人宅のポスター掲示場所を管理

#### チラシ配り活動
- ポスティングマップ (`/map/posting`): イベント単位で配布エリアを可視化
- 他のユーザーの配布済みエリアと未配布エリアが確認できる

### ユーザーの心理
- オンラインの応援がオフラインの活動につながる
- リファラルにより「広める側」になる達成感
- 地図で自分の貢献が可視化されることで達成感が持続

---

## フェーズ7: シーズン制による長期定着

### シーズンの仕組み
- シーズンごとにXP・ランキングがリセットされる
- 過去シーズンの記録は閲覧可能 (`/seasons/[slug]/ranking`)
- シーズン固有のバッジが存在する

### 現在のシーズン構成
| シーズン | 期間 | テーマ |
|---------|------|--------|
| Season 1 | 2025/6/1 - 2025/7/19 | ～2025年参院選 |
| Season 2 | 2025/8/13 - 2026/2/7 | ～2026年衆院選 |
| Season 3 | 2026/2/9 - 現在 | 2026年春～ |

### シーズン移行時の体験
1. 新シーズン開始 → 全ユーザーが同じスタートラインに
2. 過去シーズンの順位・バッジはプロフィールに保存される
3. 「今シーズンこそ上位に入りたい」という再挑戦意欲

### ユーザーの心理
- シーズンリセットにより「今からでも遅くない」感が生まれる
- 過去のシーズン記録が蓄積されることで離脱しにくくなる
- 選挙サイクルとの連動で政治参加の実感が得られる

### 各フェーズのKPI候補

| フェーズ | 指標 |
|---------|------|
| 認知・流入 | トップページ訪問数、リファラル経由率 |
| オンボーディング | チュートリアル完了率 |
| 登録 | 会員登録完了率（LINE / メール別）、プロフィール設定完了率 |
| 初回ミッション | 初回ミッション達成率、初回シェア率 |
| 習慣化 | DAU/WAU/MAU、1人あたり月間ミッション達成数、レベル分布 |
| コミュニティ | リファラル率、地域ミッション参加率、アクティビティ投稿数 |
| 長期定着 | シーズン跨ぎ継続率、累計ミッション達成数、ランキング参加率 |
