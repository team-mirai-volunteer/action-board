## 2. AIインタビュー論点への対応整理（カバレッジ）

54名のAIインタビューで挙がった論点を、今回の改定でどう扱ったかの一覧。**「反映した」「あえて反映しなかった（背景つき）」「規程ではなく運用ガイドで扱う」「次回改定に送る」の4分類**で整理している。組織活動本部内で「どの意見を、なぜ、どう扱ったか」の認識を合わせるためのセクション。

### 全体構造の読み方

- 規程の明文化そのもの・「調整・支援役」の位置づけ・退任基準の明確化・相談窓口には**肯定的な受け止めが多数**。
- 何らかの未解消の不満が残る人は**3割前後（15〜20名）**、構造的な不満を強く持つコア層は**1割強（6〜8名。#6, #10, #16, #21, #23, #24, #32が中心）**と見積もる。
- 残る不満は**正反対の2方向に割れている**。「本部の統制・審査を強めろ」（#14, #17, #26）と「地域の自律・共創を守れ」（#6, #16, #23）は同時に満たせないため、**中間ポジション（入口は開く＋解任は記録可能な行為ベースに限定）を意図的に取った**。これは規程の欠陥ではなく、本部としての立場の選択である。
- 残る不満への最大の手当ては条文ではなく、**8/27の資料公開時に「意見は認識したうえで、こう判断した」を理由つきで示すこと**と、**第14条の改定提案ルートが実際に機能すること**（「これで固定します」にしない。#52）。

### 反映した論点（今回の改定5箇所に対応）

| 論点 | 主な声 | 反映内容 |
|---|---|---|
| 立替払い禁止と現地払い実務の矛盾 | #2, #11, #23, #49 | 第4条に道路使用許可費用等の例外を追記 |
| 非稼働整理の応答期間が短すぎる | #7, #10, #11, #33 | 計2週間→計4週間に延長（#10の「せめて4週間」と一致） |
| 見送り基準の曖昧さ（「本部にとって扱いやすい人だけが正式メンバーになるのでは」懸念） | #6, #24, #54 | 満了で**自動的に正式加入（オプトアウト方式）**。例外は記録可能な違反・第5条不備・本人辞退の3つに限定し、地域からの申告単独では移行を止めない（人気・相性による選別を構造的に排除） |
| 見送りによるアンチ化・居づらさ | #5, #30, #33 | 同上。自動移行により、見送り自体が例外中の例外になる設計 |
| 「お試し」という名称の圧力・審査感 | #33 ほか | 「ウェルカム期間」に改称 |
| 現場での進行指揮と「権限なき調整役」の齟齬（平時分） | #21, #51 | 第3条Don'tに、第4条の実施権限との整合を明確化する注記を1文追加 |

| 論点 | 主な声 | 判断と背景 |
|---|---|---|

| エリア区分の見直し | #16, #31, #47 | **現行14区分を維持（決定済み）**。区分自体の再編は活動の立ち上がりに応じて本部が行う（第7条）。所属エリアの定義・複数県への関わり方は運用ガイドで扱う |

## 3. 規程本文（改定版）

（新名称）運営規程（案）
※チームの新名称は別途決定し、決定後に本書の表記を差し替える。

### 第1条 目的・基本理念

本規程は、チームみらい（以下「党」）の地域活動における（新名称）の役割、加入・退任の要件および手続きを定め、地域活動が安心・公正・持続可能に行われることを目的とする。

（新名称）の運用にあたっては、以下を大方針とする。

- 楽しめること（活動が心理的プレッシャーにならないこと）
- 強制しないこと（活動・勧誘をノルマ化しないこと）
- 義務化しないこと（新規サポーター獲得等を義務としないこと）

（新名称）は「地域を統率する権限者」ではなく、地域で活動する全ての人が安心して活動できる環境をつくる調整・支援役である。本規程のいかなる条項も、（新名称）のメンバーに党を代表する権限、党の意思決定権限、他のサポーターに対する指揮命令権限を付与するものではない。

### 第2条 定義

- **サポーター**：党の活動に参加、または応援する者。本部所定の方法による登録をもってサポーターとなる。
- **本部**：組織活動本部。
- **（新名称）**：地域コミュニティの運営支援を担う、サポーターの中の登録メンバーにより構成されるチーム。

### 第3条 役割定義

（新名称）は、地域で活動する全ての人が党の「5つのValue」を体現でき、安心して楽しく活動できる環境づくりを担う。

（新名称）は、地域のサポーター全体を代表する立場ではなく、党を代表・代行して発言や判断を行う立場でもない。あくまで情報共有、サポーターの受け入れ、イベント調整、地域の声を拾うための補助的な役割である。メンバーの発言・提案は一個人のものであり、「サポーターの総意」や「党の意向」として扱ってはならない。

**Do（やること）**

- 新しく参加した人を歓迎し、誰もが入りやすく居心地のよい場をつくる
- 地域のイベント・活動の日程調整や情報整理で、みんなの活動をスムーズにする
- 地域の声・アイデア・良い事例を本部に届け、地域と党をつなぐ
- 本部からのお知らせやルールを、地域のみんなにわかりやすく伝える
- 困りごとや対立の芽に早めに気づき、一人で抱え込まずに本部と共有して解決する

**Don't（やってはいけないこと）** ※例示であり限定列挙ではない

- 価値観の押し付け（「私はこう思うので、合わせてください」等）
- 不公平な扱い・特定の人への偏り
- 独断の指示、本部方針と食い違う独自判断
  > **【変更・追記】** 第4条に基づき地域組織が企画・実施するイベント・活動について、当日の進行に必要な範囲の調整（配置案内・時間調整等）を行うことは、上記の「独断の指示」には該当しない。禁止されるのは、本部方針に反する独自の判断や、党の意思決定に関わる指示である。
- クローズドな場で物事を決めること（特定の人だけへのDM等）

### 第4条 党本部と地域組織の役割分担

基本的な考え方は「活動は地域が主役、権限・管理は本部が担う」であり、分担は次のとおりとする。

| 領域 | 党本部 | 地域組織（（新名称）を含む） |
|---|---|---|
| 地域活動・イベント | 全体方針・ガイドラインの提示、後方支援（物品・ノウハウ提供等） | イベント・交流会・ポスティング等の企画・実施、参加の呼びかけ |
| 広報・情報発信 | 公式Web・全SNSアカウントの運用、広報物の制作（デザイン・印刷） | 素材の提供（現場の写真・動画を本部に送る等）、ポスター掲示・ビラ配り、本部投稿の拡散（個人アカウント等で） |
| 個人情報 | サポーター・党員・イベント参加者・（新名称）参画者の情報管理 | 個人情報を活用する活動は本部へ依頼（アクセス権は本部が管理） |
| 財務・経理 | 全予算管理・決済、政治資金収支報告書の作成・提出 | 必要経費の申請（本部が直接支払う形とし、原則建て替え不可）。**【変更・追記】** ただし、道路使用許可の申請費用等、現地でしか支払えない費用に限り、例外的に立替を認める。申請・精算の運用フローは本部が別途定める |

個人情報の取り扱い：（新名称）のメンバーは、サポーターから個人情報（氏名・連絡先等）を収集してはならない。個人情報の収集・管理を行えるのは本部のみとし、独自の名簿作成・保持は行わない。

（新名称）のメンバーは、上記の本部所管事項について、独自判断で契約・支出・公式発信・個人情報取得を行ってはならない。

### 第5条 加入要件

（新名称）に加入する者は、加入時点および在任中を通じて、次の全てを満たすものとする。

1. 満18歳以上であること。
2. 反社会的勢力に該当せず、また関与していないこと。
3. 党のビジョン・5つのValue・本規程および本部が定めるガイドラインに同意していること。
4. 過去に本規程への重大な違反により退任・登録抹消となり、本部が定める期間を経過していない者でないこと。
5. 第9条に定める兼職・利益相反の状態にないこと。

### 第6条 加入方法

（新名称）への加入申請は、全てのサポーターに開かれている。エリア・地域を問わず、全国で同一の方法による。

**加入フロー：**

1. 加入を希望するサポーターは、本部所定のフォームから申請する。
2. 本部はフォーム受領後、登録確認（第5条の資格要件の確認）を行い、即時に**「ウェルカムメンバー」**として登録する。**【変更】**（旧称：お試しメンバー）
3. **ウェルカム期間**は登録から3ヶ月間とする。**【変更】**（旧称：お試し期間。期間の長さ自体は変更なし）ウェルカム期間中の役割・チャンネル等への参加範囲は、正式メンバーと同等とする。
4. **【変更】** ウェルカムメンバーは、ウェルカム期間の満了をもって**自動的に正式メンバーとなる**。満了にあたって、本人への意思確認や申請手続きは求めない。ただし、次のいずれかに該当する場合はこの限りではなく、本部が本人に連絡のうえ個別に対応する。
   - ① 期間中に、第3条のDon'tまたは第9条3項の禁止行為に該当する、記録可能な違反があった場合
   - ② 第5条の資格要件に不備がある場合
   - ③ 本人から辞退の申し出があった場合

**兼任を制限する立場の例とその対応：**

- 党と利益相反する団体の役員等、（新名称）としての公正な活動が困難となる立場

**禁止する行為の例：**

- （新名称）の立場を利用した営業・勧誘（宗教・マルチ商法・自己の事業への誘導等）
- 党の資源（広報物・チラシ・物品・予算・データ等）を、私的目的に流用すること
- 党の内部情報の外部への提供

**制限しないもの**：他の政党・政治団体の党員・サポーター・支持者であること自体（第2項に定める役職に就いている場合を除く）、個人としての投票・応援、過去の立候補歴。

本条による退任は懲戒ではなく役割整理であり、退任者はサポーターとしての活動を引き続き歓迎される。事由が解消し第5条の要件を満たす場合は、第6条により再加入できる。ただし第3項の禁止行為に該当する場合は、第10-2項の手続（解任）の対象となる。

### 第10条 退任（退任事由・手続）

**10-1. 退任事由**

次の各号のいずれかに該当する場合、（新名称）を退任するものとする。

1. **本人の申し出**：理由を問わず、いつでも可能である。申し出は本部へのSlackで一言伝えれば足りる。本部は申し出を受けて登録を解除し、本人へその旨を確認する。
2. **資格要件の喪失**（第5条各号のいずれかを満たさなくなった場合。第9条の利益相反を含む）
3. **非稼働**（第10-3項の手続による整理）
4. **重大なルール違反**（第10-2項の手続による解任）

**10-2. ルール違反による解任の手続（段階的プロセス）**

解任は、記録可能な具体的行為（第3条4項のDon'tに該当する行為、第4条の越権行為、第9条3項の禁止行為、サポーターガイドライン・アンチハラスメントポリシーその他本部が定めるルールへの違反等）を根拠とする場合に限り行うことができる。違反行為が事後に判明した場合も、記録・確認できる限り本項の手続の対象とする。

違反行為があった場合、本部はまず、必要に応じて事実確認や本人へのヒアリング等を行ったうえで、注意・改善の要請を行う。注意・改善の要請を受けたにもかかわらず同様の行為が繰り返される場合は、本部の合議により解任を決定する。

緊急性が高い場合（法令違反、個人情報の漏洩、党の資源の流用等）は、段階を省略して即時の活動停止（登録一時停止）を行うことができる。

解任の決定・根拠・経緯は本部にて記録し保管する。多数決や署名等、特定メンバーへの人気・支持の多寡を解任の根拠としない。

**10-3. 非稼働メンバーの整理**

- 本部は棚卸し時に、活動が確認できないメンバーへSlackにて連絡する。
- **【変更】** 2週間以内に応答がない場合はリマインドを1回行い、さらに2週間（初回連絡から計4週間）応答がない場合、メンバーリストから削除する（削除は懲戒ではなく登録整理であり、再加入を妨げない）。（旧：1週間＋1週間の計2週間。第6条のウェルカム期間満了時の意思確認と応答期間を揃えた）
- Slackで連絡がつかない場合は、本部が把握している他の連絡手段を1回試みたうえで同様に扱う。

**10-4. 退任時の共通事項**

- 退任・解任・整理のいずれの場合も、サポーターとしての活動は原則として妨げない（第10-1項第4号〔重大なルール違反による解任〕の場合は本部が個別に判断する）。
- 退任後は、（新名称）として保有していたアカウント権限・グループ管理権限等を削除する。

  - 本人の同意を得た本人に関する情報の共有
