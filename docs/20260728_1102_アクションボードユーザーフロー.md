# アクションボード ユーザーフロー

ユーザーが実際に目にする画面とステップを整理したドキュメント。

---

## フロー1: 新規登録

### Step 1: トップページ（未ログイン）`/`

| 要素 | 内容 |
|------|------|
| ヒーロー | グラデーション背景 + 街並みイラスト + チームみらいロゴ |
| 見出し | 「アクションボード」 |
| キャッチコピー | 「テクノロジーで政治をかえる。あなたと一緒に未来をつくる。」 |
| ボタン | 「アクションボードに登録する」→ `/sign-up` |
| リンク | 「アクションボードとは？」→ オンボーディングモーダル |
| セクション群 | メトリクス → 活動タイムライン（3件）→ ランキング（今日Top3 + 全期間Top3）→ フィーチャードミッション → カテゴリ別ミッション |

### Step 2: 登録フェーズ1 — 同意 `/sign-up`

| 要素 | 内容 |
|------|------|
| 見出し | 「アクションボードに登録」 |
| リンク | 「すでに登録済みの方は こちら」→ `/sign-in` |
| 入力 | 生年月日（年/月/日 セレクト） |
| 折りたたみ | 「なぜ生年月日が必要ですか？」 |
| バリデーション | 18歳未満はエラー表示 |
| チェックボックス | 「利用規約 および プライバシーポリシー に同意する」 |
| ボタン | 「次へ進む」（同意+年齢OK時のみ有効） |
| 案内文 | 「義務や費用は一切発生しません」 |

### Step 3: 登録フェーズ2 — ログイン方法選択

同じ `/sign-up` ページの2画面目。

| 要素 | 内容 |
|------|------|
| ボタン（緑） | 「LINEでアカウント作成」→ LINE OAuth画面 |
| 区切り | 「または」 |
| ボタン（枠線） | 「メールアドレスとパスワードで作成」→ `/sign-up-email` |
| リンク | 「戻る」→ フェーズ1に戻る |

### Step 4A: LINE登録の場合

| ステップ | 画面 |
|---------|------|
| LINE認証画面 | LINEアプリまたはブラウザで認可 |
| コールバック `/auth/line-callback` | 「連携処理中...」ローディング表示 |
| リダイレクト | → `/settings/profile?new=true`（Step 5へ） |

### Step 4B: メール登録の場合 `/sign-up-email`

| 要素 | 内容 |
|------|------|
| 見出し | 「メールアドレスとパスワードを入力」 |
| リンク | 「他の方法でアカウント作成」→ `/sign-up` |
| 入力 | メールアドレス（placeholder: `you@example.com`） |
| 注意文 | 「※一部のメールアドレスに認証メールが届かない事象が…Gmailなどをご利用ください」 |
| 入力 | パスワード（8文字以上、半角英数） |
| ボタン | 「アカウントを作成」 |
| → 遷移先 | `/sign-up-success` |

### Step 4B-2: 登録完了 `/sign-up-success`

| 要素 | 内容 |
|------|------|
| 見出し | 「アカウント作成完了」 |
| メッセージ | 「認証メールをお送りしました。メールに記載のURLをクリックして、アカウントを有効化してください。」 |
| → 次のアクション | メール内リンクをクリック → ログイン → `/settings/profile?new=true`（Step 5へ） |

### Step 5: プロフィール設定（新規ユーザー） `/settings/profile?new=true`

ホームにアクセスしてもプロフィール未設定の場合はここにリダイレクトされる。

| 要素 | 内容 |
|------|------|
| カードタイトル | 「プロフィール設定」 |
| 説明 | 「公開されるプロフィール情報を登録します。」 |
| アバター | クリックで画像アップロード（5MB以下）+ 削除ボタン |
| 入力 | ニックネーム（必須、100文字以下） |
| 入力 | 生年月日（年/月/日 セレクト、非公開）+「なぜ必要？」折りたたみ |
| 選択 | 都道府県（必須） |
| 入力 | 郵便番号（必須、ハイフンなし7桁、非公開）+「なぜ必要？」折りたたみ |
| 入力 | X（旧Twitter）ユーザー名（オプション） |
| ボタン | 「登録する」 |
| → 遷移先 | `/`（トップページ、ログイン済み表示） |

## フロー3: トップページ閲覧（ログイン済み）

### Step 1: トップページ `/`

ログイン後のトップページ。ヒーロー部分がプロフィールカードに変わる。

| セクション | 表示内容 |
|-----------|---------|
| プロフィールカード | アバター / ニックネーム / LV.{N} / 都道府県 / {N}ポイント / 進捗バー / トップバッジ → クリックで `/users/{自分のid}` |
| 都道府県対抗カード | 「都道府県チームパワー」→ クリックで `/prefecture-team` |
| メトリクス | サポーター数 / 達成アクション数 / 動画再生回数・本数（各「詳しく見る」リンク付き） |
| 活動タイムライン | 最新3件 +「もっと見る」→ `/activities` |
| ランキング | 今日Top3 / 全期間Top3 カルーセル +「Top100を見る」→ `/ranking` |
| フィーチャードミッション | 注目ミッション（2倍XP）横スクロール |
| カテゴリ別ミッション | 🎯ミッション 見出し → 各カテゴリのミッションカード横スクロール |

#### 通知ダイアログ（条件付き表示）

| 通知 | 内容 |
|------|------|
| レベルアップ | 「サポーターレベルが アップしました！」+ レベル番号のアニメーション表示 |
| バッジ獲得（1.5秒後） | 「新しいバッジを獲得しました！」+ バッジ一覧 +「確認しました」ボタン |

## フロー4: ミッション達成

### Step 1: ミッションカード選択（トップページ内）

各ミッションカード:

| 要素 | 内容 |
|------|------|
| アイコン | ミッション固有アイコン（80x80px） |
| ステータスバッジ | 「達成済み」/「{X}/{Y}回達成」/「{X}回達成」 |
| タイトル | ミッション名 |
| 集計 | 「みんなで{N}回達成」 |
| 難易度 | 「難易度 ⭐⭐⭐」 |
| ポイント | 「{N}P」（フィーチャードは「x 2」） |
| ボタン | 「今すぐチャレンジ🔥」/「もう一回チャレンジ🔥」/「ミッションクリア🎉」→ `/missions/{slug}` |

### Step 2: ミッション詳細ページ `/missions/{slug}`

| セクション | 内容 |
|-----------|------|
| ミッション情報カード | アイコン + タイトル + 難易度バッジ + 説明文（HTML） |
| 提出フォーム | ミッションタイプに応じた入力UI（下記参照） |
| あなたの達成履歴 | 最新20件の提出一覧（日時 + 「取り消す」ボタン） |
| ランキング（無制限ミッションのみ） | このミッションのTop10 |
| 関連ミッション | 同カテゴリの他ミッション（横スクロール） |
| 未ログイン時 | 「ログインしてミッションを達成しよう」カード +「ログインする」ボタン |

#### 提出フォームの種類

| タイプ | 表示されるUI |
|--------|------------|
| LINK_ACCESS | 外部リンクボタン +「リンクを開くとミッションクリアとなります」 |
| LINK | URL入力フィールド +「ミッション完了を記録する」ボタン |
| TEXT | テキスト入力フィールド |
| EMAIL | メールアドレス入力フィールド |
| IMAGE | 画像アップロード（10MB以下） |
| IMAGE_WITH_GEOLOCATION | 画像アップロード + 位置情報 |
| QUIZ | 学習リンク → 各問題にラジオボタン →「回答する」→ 結果表示（正解/不正解 + 解説） |
| REFERRAL | 「あなた専用紹介URL」+ QRコード +「紹介URLをコピー」ボタン |
| POSTER | ポスター枚数入力（地図連携） |
| POSTING | 配布枚数入力（地図連携） |
| RESIDENTIAL_POSTER | ポスター枚数 + 郵便番号入力 |
| YOUTUBE | YouTube動画URL入力 |
| YOUTUBE_COMMENT | YouTubeコメント検証 |
| NONE | 「ミッション完了を記録する」ボタンのみ |

共通フィールド: 「補足説明（任意）」テキストエリア

### Step 3: ミッション完了ダイアログ

提出成功後に表示。

| 要素 | 内容 |
|------|------|
| タイトル | 「おめでとうございます！」 |
| メッセージ | 「{ミッション名}を達成しました！」 |
| OGP画像 | 動的生成されたミッション完了画像 |
| 見出し | 「シェアして応援の輪を広げよう」 |
| シェアボタン | X / Facebook / LINE / ネイティブシェア / URLコピー |
| ボタン | 「このまま閉じる」 |

### Step 4: XP獲得トースト

ダイアログを閉じた後、画面下部にXP獲得アニメーションが表示される。

## フロー12: オンボーディングチュートリアル

| ステップ | 画面内容 | ボタン |
|---------|---------|--------|
| 1 | ロゴ +「アクションボード」ウェルカム画面 | 「説明を聞く」 |
