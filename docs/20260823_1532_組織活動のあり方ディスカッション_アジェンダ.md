# 組織活動のあり方ディスカッション アジェンダ

## 0. まず、PMからの進め方の提案

依頼の趣旨（認識合わせ → 目的の再確認 → OKRの妥当性 → アクション棚卸し）を1回のMTGに全部詰めると、確実に棚卸しが空中戦になります。**「Why（目的）を決める会」と「What/How（OKR・アクション）を決める会」を分けることを推奨**します。

| 案 | 構成 | 向いているケース |
| --- | --- | --- |
| **A案（推奨）：2回シリーズ** | 第1回（90分）：認識合わせ＋組織活動本部の目的の言語化＋現行OKRの妥当性チェック（論点出しまで）<br>第2回（90分・1〜2週間後）：OKR改訂案の議論＋アクション棚卸し | 参加者が多い／転換への感情的な消化が必要／OKR改訂を丁寧にやりたい |
| B案：1回集中（120分） | 本ドキュメントのタイムテーブルを通しで実施 | 日程が取れない／参加者が既にヒアリング内容を消化済み |

**進め方の工夫（どちらの案でも推奨）**

1. **事前非同期コメント方式**：全体会の28ビジョン回と同じやり方。ヒアリング議事メモと現行OKRを事前共有し、コメント・疑問を書き込んでもらう。当日は論点が並んだ状態から始める（ゼロから話さない）
2. **「ものさし」を最初に合意する**：個別の議論に入る前に、判断基準を1本に絞る。提案：**「その活動・KRは、サポーターが『参加者』または『伝道師』になることに直接効くか？」**。以降のOKRチェックも棚卸しも、全部この問いで判定する
3. **9月の28ビジョン回と接続する**：全体会の次回は各本部の28ビジョン（中期計画）を議論する回。本MTGのアウトプット（目的の言語化・OKR改訂の方向性）は、そのまま組織活動本部の28ビジョンドラフトの材料になる。締切をそこから逆算する
4. **議事録は当日中にオープンに共有**：「決まったことは決まった時点で記録して周知」（全体会の打ち手）に準拠

以下、B案（120分・1回）のフルアジェンダを記載します。A案の場合は第1回＝パート1〜4、第2回＝パート5〜6に分割してください。

### このMTGの目的

1. **認識合わせ**：党の戦略転換（デジタル民主主義への全振り）と、それを受けた組織活動本部の役割の変化を、全員が「自分の言葉で説明できる」状態にする
2. **目的の言語化**：新戦略のもとでの組織活動本部の目的（Why）を1〜2文で言語化する
3. **OKRの検証**：現行OKR（O1〜O5）が新しい目的に照らして正しいかを検証し、改訂の論点を特定する
4. **アクションの棚卸し**：目的から逆算して、既存・新規の活動を「続ける／変える／やめる／検証する」に仕分ける

### このMTGのゴール（終了時に達成していたい状態）

- [ ] 「なぜ組織活動本部の目標が変わるのか」に全員が納得している（納得できない点はレイズされ、記録されている）
- [ ] 組織活動本部の目的が1〜2文のドラフトとして書かれている
- [ ] 現行OKRの各Objectiveに「維持／再定義／削除・縮小／追加すべき観点」の仮判定がついている
- [ ] 既存活動の一覧が仕分けされ、「やめる／縮小」に最低1つは入っている（何も捨てないなら、その理由を全体で確認済み）
- [ ] OKR改訂のDriver（PM）・Approverと期日が決まっている
- [ ] 未解決論点がパーキングロットに記録され、持ち帰り担当が決まっている

### このMTGで「決めないこと」（スコープ外）

- 改訂OKRの最終文言（本MTGは論点出しと方向づけまで。策定は決めたオーナーが実施）
- 広聴本部との役割分担の最終決定（協議の場を別途設定済み。ここでは組織活動本部としてのスタンス整理まで）
- コミュニティプラットフォーム（O5）のツール選定などの個別実装判断
- 人事・体制の個別論

## 1. オープニング（10分）

- 本MTGの目的・ゴール・決めないことを確認する
- **「ものさし」の合意**：以降のすべての議論の判断基準を先に置く
  - 提案：**「その活動・KRは、サポーターが『参加者』（政策提案に意見を述べ声を届ける）または『伝道師』（デジタル民主主義を広め仲間を増やす）になることに直接効くか？」**
- グランドルールの共有
  - 全体会の党首メッセージに準拠：**レイズは自由、オープンディスカッション。決めるのはオーナー（disagree and commit）**
  - 「これまでやってきたことの否定」の場ではなく、「フェーズが守→破に変わった」ことへの適応の場である、と最初に明言する
  - 結論が出ない論点はパーキングロットへ（放置せず持ち帰り担当を決める）

## 2. インプット：党の戦略転換＋ヒアリング結果（15分）

事前読み込み前提で、要点の再確認と事前コメントから抽出した論点の貼り出しを行う。

**全体会スライドから押さえるポイント**

- **ビジョン**：デジタル民主主義（人類の民主的で集団的な意思決定OS）の実現。2028年に「デジタル民主主義の型が機能する」状態を目指す
- **戦い方の転換**：「全科目60点」ではなく「一科目1000点」。既存政党と同じことを同じようにやる慣性はスタートアップにとって最悪の戦い方。捨てるものは捨てて集中する
- **Positions（党首の現時点の考え）のうち組織活動に効くもの**：足元の支持率は追わない／議席が減るリスクをおそれない／守はもう終わり、破を進める／選択と集中
- **組織活動本部のKPT（全体会より）**：Keep＝党大会完遂・RCVグッズ投票の実運用／Problem＝**サポーター登録33,000人に対し実働約1,000名**／Try＝新規オンボーディングと非アクティブ再接触の設計・運用
- **これまでの前提（対比として明示）**：選挙で勝つためのサポーターとりまとめ組織。ポスター・ポスティング等の物理活動、地方選に向けたリーダーチーム立ち上げ

**党首ヒアリングから押さえるポイント**（詳細は付録A）

- リソースを「デジタル民主主義の実現」に全振りする方向で試行することに合意
- サポーターの役割の再定義：数より理解。**「参加者」と「伝道師」**
- 地域活動は維持しつつ、テーマ別（AI・福祉・子育て等）クラスターを立ち上げる
- ポスティングは効果測定データ取得後、10月頃の再開目標。ポスターは条例確認コストが大きく要検討
- 広聴本部との役割分担が論点（声を聴くサイクル＝広聴寄り／サポーター増加・マーケ＝組織活動寄り？）。まずAIタウンミーティング等の**成功事例創出を優先**
- サポーターが年1回集まる文化祭的オフラインイベントの構想
- 関連人事：石田加奈子さんが組織活動本部に合流し、組織活動の改善とテーマ別コミュニティの立ち上げを担当

## 3. 認識合わせディスカッション（20分）

疑問・違和感・懸念を**出し切る**パート。ここで消化しないと後半が空中戦になるため、時間を惜しまない。

**問いの例（ファシリテーターが順に投げる）**

1. 「組織活動本部のミッションが変わる」を、自分の言葉で言うとどうなるか？（数名に話してもらい、ズレを確認する）
2. 「選挙で勝つための組織」から「デジタル民主主義を体感してもらう組織」への転換で、**変わらないもの**は何か？（例：サポーターとの信頼関係、地域のつながり、リーダーチームで培った人的資産）
3. これまでの活動（ポスティング、リーダーチーム立ち上げ等）に注いだ努力はどう位置づけられるか？懸念や引っかかりはないか？
4. サポーター・リーダーチームのみなさんにこの転換をどう伝えるか？伝え方を誤ると何が起きるか？
5. 「実働1,000名／登録33,000人」という数字を、新戦略のもとではどう解釈すべきか？（数を追わないなら、何を追うのか）

**チェックポイント**：認識が揃ったかを確認（例：Fist to Five）。3未満の人にはその場で理由をレイズしてもらい、記録する。

## 4. 組織活動本部の目的（Why）の言語化（15分）

「とにかく目的は何で、だから何をしていくべきなのか」の**「目的は何で」**をここで固める。OKR・棚卸しはすべてここから逆算する。

**進め方**

1. （5分）各自が「新戦略のもとでの組織活動本部の目的」を1文で書く（例のフォーマット：「組織活動本部は、＿＿＿のために、＿＿＿する組織である」）
2. （7分）貼り出して共通要素と相違点を確認し、ドラフト1〜2案に収束させる
3. （3分）ドラフトを仮決定（最終化は本部長＝Approver）

**たたき台（ファシリテーターが必要なら提示）**

> 組織活動本部は、デジタル民主主義の実現のために、サポーターが「参加者」として声を届け、「伝道師」として仲間を広げられる場と仕組みをつくる組織である。

**あわせて確認する論点**

- 広聴本部との境界：「声を聴き政策へ反映するサイクル」はどこまで組織活動が持つか（＝目的文に含めるか）。※最終決定は広聴本部との協議の場で
- 「選挙で勝つ」は目的文から消えるのか、「長期的にはデジタル民主主義の成功が選挙勝利につながる」として位置づけ直すのか

## 5. 現行OKRの妥当性チェック（25分）

現行OKR（付録B）を1つずつ「ものさし」に当てて検証する。各Objectiveを**維持／再定義／削除・縮小**のいずれかに仮判定し、**追加すべき観点**を洗い出す。

**PMによる事前分析（当日のたたき台。結論ではなく論点として使う）**

| Objective | 事前分析・論点 |
| --- | --- |
| **O1：関わり方を選べる**（リーダーチームリセット、テーマ型コミュニティ8個、宣言率60%） | 方向はヒアリング結論（テーマ別クラスター設置）と整合。ただしKRは**器の数と宣言率**であり、器の中で「デジタル民主主義の理解・実践」が起きるかは測っていない。問い：コミュニティの活動テーマにデジタル民主主義の実践（いどばた・AIタウンミーティング等への参加）をどう組み込むか |
| **O2：新規オンボーディング**（参加率80%、転換率30%） | 全体会のTryと整合。ただし「数より理解」の観点では、オンボーディングの中身に「デジタル民主主義とは何か」の理解体験が入っているかが本丸。問い：転換率のような**量のKR**に加えて、**理解・体感のKR**が要るのでは |
| **O3：非アクティブ再活性化**（20%以下、再参加率60%） | 全振り戦略下での**優先度**が最大の論点。33,000人全員の再活性化を追うのは「全科目60点」的発想に戻る恐れ。問い：非アクティブ対応は「つながり維持（低コスト）」に留め、リソースは参加者・伝道師づくりに寄せるべきでは |
| **O4：自律的コミュニティ活動**（自発的活動 月16回以上、大型イベント） | 回数KRは**活動の中身を問わない**。ポスティングでも1回、AIタウンミーティングでも1回になってしまう。問い：「デジタル民主主義の実践を含む活動」に限定してカウントすべきか。KR4.3の大型イベントはヒアリングの文化祭構想と接続して具体化 |
| **O5：コミュニティプラットフォーム**（10月末MVP、Slack5000名の移行率90%） | 最大の要検討。①ヒアリングで「開発本部へ優先度を説明できない」課題が既に指摘されており、開発リソースの確保が不確実 ②移行率90%は高リスクKR ③既存のアクションボードとの関係整理が先（新規開発か拡張か）。問い：**成功事例（AIタウンミーティング等）が先、プラットフォームは後**という順序にすべきでは |

**現行OKRに欠けている観点（追加候補）**

- **「参加者」のKR**：政策提案への意見数、いどばた等の熟議への参加者数 など
- **「伝道師」のKR**：サポーター経由の紹介・新規接点数（キャラバンでは紹介経由の新規率91.7%と突出）など
- **成功事例創出のKR**：AIタウンミーティング等「サポーター巻き込みの成功事例」を◯件つくる（ヒアリングの結論そのもの。一丁目一番地に置く候補）
- **ポスティング効果測定**：10月の再開判断に必要なデータ設計（何を測るか・比較対照をどう置くか）
- **広聴本部との役割分担協議**の完了

**アウトプット**：Objectiveごとの仮判定と、OKR改訂のDriver（PM）・Approver・ドラフト期日（9月の28ビジョン回から逆算）

## 6. アクション棚卸しと仕分け（25分）

「だから何をしていくべきなのか」を具体化する。パート4の目的文とパート5の判定を踏まえて仕分ける。

**進め方**

1. （5分）既存・新規の活動を付箋で洗い出す（事前ワーク＋下記チェックリストに追記）
2. （15分）「ものさし」×「投下リソースに見合うか（効果測定できるか）」で4分類に仕分ける
3. （5分）全体で眺めて違和感を確認。**「やめる／縮小」が空欄なら「本当に何も捨てなくてよいのか？」を全体に問い直す**

**仕分けカテゴリと叩き台**

| 分類 | 意味 | 叩き台（議論して動かす） |
| --- | --- | --- |
| **続ける（強化）** | 新戦略に直結。リソースを寄せる | テーマ型コミュニティ立ち上げ、AIタウンミーティング等の成功事例づくり、キャラバンのアクションボード登録・フォローアップ、新規オンボーディング（理解体験を組み込んで） |
| **変える（再定義）** | 活動は維持するが目的・KPIを付け替える | 地域活動（選挙準備→デジタル民主主義の地域実践の場へ）、非アクティブ対応（再活性化→低コストのつながり維持へ）、大型イベント（活動発表＝文化祭構想として再設計） |
| **検証する（データ待ち）** | 効果測定してから判断 | ポスティング（効果測定→10月頃再開目標）、ポスター掲示（条例確認コストと効果の見合い）、コミュニティプラットフォーム（アクションボード拡張との比較検討） |
| **やめる／縮小** | 新戦略への寄与が薄い。勇気を持って捨てる | （議論して記入。「捨てるものを決めて捨てる」を実践するパート） |

**洗い出し漏れ防止チェックリスト**

- 物理活動：ポスティング、ポスター、街頭系
- 地域組織：旧リーダーチーム関連の残タスク、地域コミュニティ運営
- サポーター管理：オンボーディング、非アクティブ接触、アクションボード運用、ティア・宣言まわり
- イベント：党大会運営、キャラバン支援、文化祭構想
- 新規：テーマ型クラスター、AIタウンミーティング等の巻き込み事例、コミュニティプラットフォーム
- 他本部連携：広聴本部（声を聴くサイクル）、開発本部（ツール依頼・優先度説明）、広報本部（発信）

**アウトプット**：仕分け済みの活動一覧（記録してSlackでオープンに共有）

## ファシリテーション上の留意点（PMメモ）

- **「否定」ではなく「フェーズ転換」のフレーミングを最初に置く**。ポスティングや地域組織立ち上げは当時の戦略（守）では正しかった。全体会でも「組織内の誰かが悪いという話ではない」と明言されている
- **パート3（認識合わせ）を削らない**。ここが浅いと棚卸しで「やめる」判断ができず、全部「続ける」に倒れる（＝全科目60点への逆戻り）
- **OKRチェックでは「Objectiveの正しさ」と「KRの測り方」を区別する**。Objectiveは合っているがKRが量に偏っている、というケースが多い（事前分析参照）
- **O5（プラットフォーム）の議論が長引きやすい**ので、ツール選定の各論に入ったら「順序の問い（成功事例が先か、基盤が先か）」に引き戻す
- 職員（本部外）の参加者には、他本部からの見え方・連携上の困りごとを意識的に発言してもらう

## 付録A：党首ヒアリング議事メモ（再掲・原文）

参加者：安野さん、湯田さん、武藤さん

### 党の戦略：デジタル民主主義への集中

- 議論の概要
  - 他領域で平均的な成果を目指すより、強みである「デジタル民主主義の実現」にリソースを集中し、突出した成果（千点を目指す）を狙うべきとの提案
  - 全てを平均的にこなす（全科目60点）と、党の独自価値が薄まる懸念
  - 長期的には、デジタル民主主義の成功が選挙勝利にもつながるとの認識を共有
- 結論
  - 党の活動方針として、リソースを「デジタル民主主義の実現」に全振りする方向で試行することで合意

### サポーターの役割と活動方針

- 議論の概要
  - サポーターの数を増やすより、「デジタル民主主義とは何か」を理解してもらう活動が重要
  - サポーターの役割は以下の2点：
    - 政策提案に意見を述べ、声を届ける「参加者」
    - デジタル民主主義の活動を広め、仲間を増やす「伝道師」
  - 関心トピック（AI、福祉、子育て等）や地域別に活動できるクラスター設置を提案
  - ポスティングやポスター掲示などの物理活動は、投下リソースに見合うか要検討。特にポスターは条例確認の手間が大きい
- 結論
  - 地域活動は維持しつつ、デジタル民主主義の実現を目的としたテーマ別活動を立ち上げる
  - ポスティング活動は効果測定のデータ取得後、10月頃の再開を目標に進める

### 組織体制と部門間の連携

- 議論の概要
  - 組織活動本部と広聴本部の役割が重複し、特にデジタル民主主義の実践で境界が曖昧
  - サポーターの声を聴き政策へ反映するサイクルは広聴本部の役割に近いが、サポーター増加（マーケティング）は組織活動本部の役割ではないかとの意見
  - 役割分担の明確化、もしくは組織統合の可能性について議論
  - 開発本部へ協力依頼する際、組織活動の優先度を明確に説明できない課題がある
- 結論
  - まずサポーター巻き込みの成功事例（例：AIタウンミーティング）創出を優先
  - 広聴本部と連携し、役割のすみ分けについて協議の場を設ける

### オフラインイベントの開催

- 議論の概要
  - サポーターが年1回集まるオフラインの場（文化祭のようなイベント）の設置を提案
  - 党員向け党大会とは別に、サポーターが交流し各地域の活動を発表する機会を設けることで、自律的活動の促進を期待
  - イベント運営にもサポーターが関与する構想を共有

### 次の予定

- ポスティング用制作物を他部門に依頼（10月頃の再開を目標）
- 広聴本部と連携し、組織の役割分担について協議
