## この会の目的

1. **認識合わせ**：党の戦略転換（デジタル民主主義への全振り）と、それを受けた組織活動本部の役割の変化を、全員が自分の言葉で説明できる状態にする
2. **目的の言語化**：新戦略のもとでの組織活動本部の目的（Why）を1〜2文で言語化する
3. **OKRの確認**：現行OKRが決定済みかドラフトかを踏まえ、妥当性チェックまたはゼロからの検討を行う
4. **アクションの棚卸し**：既存・新規の活動を「続ける／変える／やめる／検証する」に仕分ける

## ゴール（終了時に達成していたい状態）

- 「なぜ組織活動本部の目標が変わるのか」に全員が納得している
- 組織活動本部の目的が1〜2文のドラフトとして書かれている
- OKRについて「確定した妥当性の判定」または「検討の方向性」のどちらかが得られている
- 既存活動が仕分けされ、「やめる／縮小」に最低1つは入っている
- OKR改訂（または策定）のDriver・Approverと期日が決まっている
- 未解決論点がパーキングロットに記録され、持ち帰り担当が決まっている

## この会で決めないこと

- OKRの最終文言（本会は判定・論点出しまで）
- 広聴本部との役割分担の最終決定（別途協議の場を設定）
- コミュニティプラットフォームのツール選定などの個別実装判断
- 人事・体制の個別論

## 1. オープニング（5分）

- 目的・ゴール・決めないことを確認する
- **「ものさし」の合意**：「その活動・KRは、サポーターが『参加者』（政策提案に意見を述べ声を届ける）または『伝道師』（デジタル民主主義を広め仲間を増やす）になることに直接効くか？」を以降すべての判断基準にする
- グランドルール：レイズは自由・オープンディスカッション、決めるのはオーナー（disagree and commit）。「これまでの否定」ではなく「フェーズが守→破に変わったことへの適応」の場だと明言する。結論の出ない論点はパーキングロットへ

## 2. インプット：党の戦略転換＋ヒアリング結果（10分）

事前読み込み前提で要点のみ再確認する。

- **ビジョン**：デジタル民主主義（人類の民主的で集団的な意思決定OS）の実現
- **戦い方の転換**：「全科目60点」ではなく「一科目1000点」。捨てるものは捨てて集中する
- **組織活動本部のKPT**：Problem＝**サポーター登録33,000人に対し実働約1,000名**
- **ヒアリング結論**：サポーターの役割は「参加者」と「伝道師」。地域活動は維持しテーマ別クラスターを新設。ポスティングは効果測定後10月頃再開目標。広聴本部との役割分担は別途協議、まずAIタウンミーティング等の成功事例創出を優先

詳細は付録A参照。

## 3. 認識合わせディスカッション（20分）

疑問・違和感・懸念を**出し切る**パート。ここが浅いと後半の棚卸しが空中戦になる。

1. 「組織活動本部のミッションが変わる」を自分の言葉で言うとどうなるか？
2. 「選挙で勝つための組織」から「デジタル民主主義を体感してもらう組織」への転換で、**変わらないもの**は何か？
3. これまでの活動（ポスティング、リーダーチーム立ち上げ等）に注いだ努力はどう位置づけられるか？
4. サポーター・リーダーチームへこの転換をどう伝えるか？
5. 「実働1,000名／登録33,000人」を新戦略のもとでどう解釈すべきか？

**チェックポイント**：Fist to Fiveで認識が揃ったか確認。3未満の人には理由をレイズしてもらい記録する。

## 5. OKRの確認・検討（20分）

冒頭で、事前確認の結果（決定済み／ドラフト）をファシリテーターが共有し、以下のどちらかに進む。

### 5-A．決定済みの場合：妥当性チェック

各Objectiveを「ものさし」に当て、**維持／再定義／削除・縮小**を仮判定する。PMによる事前分析（O1〜O5）は付録Cを参照。特に論点になりやすい点：

- O1・O2：器や参加率などの「量」のKRはあるが、「デジタル民主主義の理解・実践」を測るKRが薄い
- O3：全振り戦略下で非アクティブ再活性化にどこまで優先度を割くか
- O4：活動回数のKRは中身を問わない（デジタル民主主義に関係ない活動でもカウントされてしまう）
- O5：開発リソースの確保が不確実。「成功事例が先、プラットフォームは後」で良いか

### 5-B．未決定／ドラフトの場合：ゼロからの検討

- 付録Bはあくまで「たたき台」として扱う
- パート4で言語化した目的文から、Objectiveを洗い出し直す（付録Cの分析は参考情報として使ってよい）
- この場で決め切らず、方向性と論点整理までにする

**アウトプット**：OKR（改訂 or 新規策定）のDriver（PM）・Approver・ドラフト期日を決める（9月の28ビジョン回から逆算）

## ファシリテーション上の留意点

- 「否定」ではなく「フェーズ転換」のフレーミングを最初に置く
- パート3（認識合わせ）を削らない。浅いと棚卸しで「やめる」判断ができず全部「続ける」に倒れる
- OKRが未決定だった場合、パート5は時間が足りなくなりやすい。方向性の合意までで区切り、詳細策定は別会に回す
- 職員（本部外）の参加者には他本部からの見え方を意識的に発言してもらう

## 付録A：党首ヒアリング議事メモ（再掲・原文）

参加者：安野さん、湯田さん、武藤さん

### 党の戦略：デジタル民主主義への集中

- 他領域で平均的な成果を目指すより、強みである「デジタル民主主義の実現」にリソースを集中し、突出した成果（千点を目指す）を狙うべきとの提案
- 全てを平均的にこなす（全科目60点）と、党の独自価値が薄まる懸念
- 長期的には、デジタル民主主義の成功が選挙勝利にもつながるとの認識を共有
- **結論**：党の活動方針として、リソースを「デジタル民主主義の実現」に全振りする方向で試行することで合意

### サポーターの役割と活動方針

- サポーターの数を増やすより、「デジタル民主主義とは何か」を理解してもらう活動が重要
- サポーターの役割：政策提案に意見を述べ声を届ける「参加者」／デジタル民主主義の活動を広め仲間を増やす「伝道師」
- 関心トピック（AI、福祉、子育て等）や地域別に活動できるクラスター設置を提案
- ポスティングやポスター掲示などの物理活動は、投下リソースに見合うか要検討。特にポスターは条例確認の手間が大きい
- **結論**：地域活動は維持しつつテーマ別活動を立ち上げる。ポスティングは効果測定後10月頃の再開を目標に進める

### 組織体制と部門間の連携

- 組織活動本部と広聴本部の役割が重複し、特にデジタル民主主義の実践で境界が曖昧
- サポーターの声を聴き政策へ反映するサイクルは広聴本部の役割に近いが、サポーター増加（マーケティング）は組織活動本部の役割ではないかとの意見
- 開発本部へ協力依頼する際、組織活動の優先度を明確に説明できない課題がある
- **結論**：まずサポーター巻き込みの成功事例（例：AIタウンミーティング）創出を優先。広聴本部と連携し役割のすみ分けを協議

### オフラインイベントの開催

- サポーターが年1回集まるオフラインの場（文化祭のようなイベント）の設置を提案
- 党員向け党大会とは別に、サポーターが交流し各地域の活動を発表する機会を設けることで、自律的活動の促進を期待
- イベント運営にもサポーターが関与する構想を共有

### 次の予定

- ポスティング用制作物を他部門に依頼（10月頃の再開を目標）
- 広聴本部と連携し、組織の役割分担について協議

## 付録B：組織活動本部 OKR（原文・ステータス要確認）

※本会の事前準備の通り、これが正式決定済みか、ドラフトかを確認した上で読むこと。

**Objective 1：サポーターそれぞれが自分に合った関わり方を選べるようにする**
- KR1.1：地域組織リーダーチームを7月末までにリセット（終了）し、新たなサポーターの枠組みを展開する
- KR1.2：テーマ型コミュニティを8個以上立ち上げ、それぞれにコミュマネが3名以上配置されている
- KR1.3：全サポーターが関わり方を宣言する（宣言完了率60%以上、Slack5000名対象）

**Objective 2：新規サポーターのオンボーディングを確立し、継続参加につなげる**
- KR2.1：オンボーディングプログラムを設計・運用開始する
- KR2.2：新規サポーターの次の活動への参加率を80%以上にする
- KR2.3：アクティブサポーターへの転換率を30%以上にする（入会後6ヶ月時点）

**Objective 3：非アクティブサポーターの関係を維持・再活性化する**
- KR3.1：非アクティブサポーターの割合を20%以下に抑える（例：3ヶ月以上活動なし）
- KR3.2：定期的な接触を月1回以上実施し、再参加率60%以上を達成する
- KR3.3：「つながりが続いていると感じる」非アクティブサポーターが80%以上（サーベイ）

**Objective 4：自律的なコミュニティ活動が全国で根付く**
- KR4.1：コアで動くサポーターが地域型100名以上・テーマ型24名以上認定され、月16回以上自発的に活動している
- KR4.2：本部起点でない自発的活動が月16回以上（全国合計）継続的に実施されている
- KR4.3：活動報告・成果発表を行う大型イベントを実行する（1月 or 2月）
- KR4.4：「社会を変える一助になっている実感がある」と答えるサポーターが90%以上（サーベイ）

**Objective 5：サポーターの活動と関係を可視化・計測できるコミュニティプラットフォームを立ち上げる**
- KR5.1：要件定義を8月末までに完了し、ツール選定・開発着手する
- KR5.2：最低限機能（ティア宣言・活動ログ・非アクティブ自動検知）を10月末までにリリースする
- KR5.3：Slack5000名のプラットフォーム移行率を90%以上にする（12月末時点）
- KR5.4：プラットフォーム上でKR1〜4の計測データが自動集計できている

## 付録C：OKR事前分析メモ（PMによるたたき台・参考情報）

| Objective | 事前分析・論点 |
| --- | --- |
| O1：関わり方を選べる | 方向はヒアリング結論と整合。ただしKRは器の数と宣言率で、器の中で「理解・実践」が起きるかは測っていない。コミュニティ活動テーマにデジタル民主主義の実践をどう組み込むかが論点 |
| O2：新規オンボーディング | 「数より理解」の観点で、理解体験のKRが不足。量のKRに加え理解・体感のKRが必要では |
| O3：非アクティブ再活性化 | 全振り戦略下での優先度が最大の論点。33,000人全員を追うのは「全科目60点」への逆戻りの恐れ。低コストのつながり維持に留めるべきでは |
| O4：自律的コミュニティ活動 | 回数KRは活動の中身を問わない。「デジタル民主主義の実践を含む活動」に限定してカウントすべきか |
| O5：コミュニティプラットフォーム | 開発リソースの確保が不確実、移行率90%は高リスク、既存アクションボードとの関係整理が先。「成功事例が先、プラットフォームは後」の順序にすべきでは |

**現行OKRに欠けている観点（追加候補）**

- 「参加者」のKR：政策提案への意見数、熟議への参加者数など
- 「伝道師」のKR：サポーター経由の紹介・新規接点数（キャラバンでは紹介経由の新規率91.7%と突出）
- 成功事例創出のKR：「サポーター巻き込みの成功事例」を◯件つくる
- ポスティング効果測定：10月の再開判断に必要なデータ設計
- 広聴本部との役割分担協議の完了
