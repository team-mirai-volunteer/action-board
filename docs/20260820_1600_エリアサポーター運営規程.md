# エリアサポーター運営規程

施行日：2026年9月14日

---

### 第1条 目的・基本理念

本規程は、チームみらい（以下「党」）の地域活動におけるエリアサポーターの役割、加入・退任の要件および手続きを定め、地域活動が安心・公正・持続可能に行われることを目的とする。

エリアサポーターの運用にあたっては、以下を大方針とする。

- 楽しめること（活動が心理的プレッシャーにならないこと）
- 強制しないこと（活動・勧誘をノルマ化しないこと）
- 義務化しないこと（新規サポーター獲得等を義務としないこと）

エリアサポーターは「地域を統率する権限者」ではなく、地域で活動する全ての人が安心して活動できる環境をつくる調整・支援役である。本規程のいかなる条項も、エリアサポーターに党を代表する権限、党の意思決定権限、他のサポーターに対する指揮命令権限を付与するものではない。

### 第2条 定義

- **サポーター**：党の活動に参加、または応援する者。本部所定の方法による登録をもってサポーターとなる。
- **本部**：組織活動本部。
- **エリアサポーター**：地域コミュニティの運営支援を担う、サポーターの中の登録メンバー。

### 第3条 役割定義

エリアサポーターは、地域で活動する全ての人が党の「5つのValue」を体現でき、安心して楽しく活動できる環境づくりを担う。

エリアサポーターは、地域のサポーター全体を代表する立場ではなく、党を代表・代行して発言や判断を行う立場でもない。あくまで情報共有、サポーターの受け入れ、イベント調整、地域の声を拾うための補助的な役割である。メンバーの発言・提案は一個人のものであり、「サポーターの総意」や「党の意向」として扱ってはならない。

**Do（やること）**

- 新しく参加した人を歓迎し、誰もが入りやすく居心地のよい場をつくる
- 地域のイベント・活動の日程調整や情報整理で、みんなの活動をスムーズにする
- 地域の声・アイデア・良い事例を本部に届け、地域と党をつなぐ
- 本部からのお知らせやルールを、地域のみんなにわかりやすく伝える
- 困りごとや対立の芽に早めに気づき、一人で抱え込まずに本部と共有して解決する

**Don't（やってはいけないこと）** ※例示であり限定列挙ではない

- 価値観の押し付け（「私はこう思うので、合わせてください」等）
- 不公平な扱い・特定の人への偏り
- 独断の指示、本部方針と食い違う独自判断
  > 第4条に基づき地域組織が企画・実施するイベント・活動について、当日の進行に必要な範囲の調整（配置案内・時間調整等）を行うことは、上記の「独断の指示」には該当しない。禁止されるのは、本部方針に反する独自の判断や、党の意思決定に関わる指示である。
- クローズドな場で物事を決めること（特定の人だけへのDM等）

### 第4条 党本部と地域組織の役割分担

基本的な考え方は「活動は地域が主役、権限・管理は本部が担う」であり、分担は次のとおりとする。

| 領域 | 党本部 | 地域組織（エリアサポーターを含む） |
|---|---|---|
| 地域活動・イベント | 全体方針・ガイドラインの提示、後方支援（物品・ノウハウ提供等） | イベント・交流会・ポスティング等の企画・実施、参加の呼びかけ |
| 広報・情報発信 | 公式Web・全SNSアカウントの運用、広報物の制作（デザイン・印刷） | 素材の提供（現場の写真・動画を本部に送る等）、ポスター掲示・ビラ配り、本部投稿の拡散（個人アカウント等で） |
| 個人情報 | サポーター・党員・イベント参加者・エリアサポーター参画者の情報管理 | 個人情報を活用する活動は本部へ依頼（アクセス権は本部が管理） |
| 財務・経理 | 全予算管理・決済、政治資金収支報告書の作成・提出 | 必要経費の申請（本部が直接支払う形とし、原則建て替え不可。ただし、道路使用許可の申請費用等、現地でしか支払えない費用に限り、例外的に立替を認める。申請・精算の運用フローは本部が別途定める） |

個人情報の取り扱い：エリアサポーターは、サポーターから個人情報（氏名・連絡先等）を収集してはならない。個人情報の収集・管理を行えるのは本部のみとし、独自の名簿作成・保持は行わない。

エリアサポーターは、上記の本部所管事項について、独自判断で契約・支出・公式発信・個人情報取得を行ってはならない。

### 第5条 加入要件

エリアサポーターに加入する者は、加入時点および在任中を通じて、次の全てを満たすものとする。

1. 満18歳以上であること。
2. 反社会的勢力に該当せず、また関与していないこと。
3. 党のビジョン・5つのValue・本規程および本部が定めるガイドラインに同意していること。
4. 過去に本規程への重大な違反により退任・登録抹消となり、本部が定める期間を経過していない者でないこと。
5. 第9条に定める兼職・利益相反の状態にないこと。

### 第6条 加入方法

エリアサポーターへの加入申請は、全てのサポーターに開かれている。エリア・地域を問わず、全国で同一の方法による。

**加入フロー：**

1. 加入を希望するサポーターは、本部所定のフォームから申請する。
2. 本部はフォーム受領後、登録確認（第5条の資格要件の確認）を行い、即時に**「ウェルカムメンバー」**として登録する。
3. **ウェルカム期間**は登録から3ヶ月間とする。ウェルカム期間中の役割・チャンネル等への参加範囲は、正式メンバーと同等とする。
4. ウェルカムメンバーは、ウェルカム期間の満了をもって**自動的に正式メンバーとなる**。満了にあたって、本人への意思確認や申請手続きは求めない。ただし、次のいずれかに該当する場合はこの限りではなく、本部が本人に連絡のうえ個別に対応する。
   - ① 期間中に、第3条のDon'tまたは第9条3項の禁止行為に該当する、記録可能な違反があった場合
   - ② 第5条の資格要件に不備がある場合
   - ③ 本人から辞退の申し出があった場合
5. 前項①〜③以外の理由により正式加入を見送ることはしない。地域や他のメンバーからの懸念・申告は、①に該当する記録可能な行為が確認できる場合に限り対応の対象とし、人気・支持の多寡や相性を理由に移行を止めることはない（申告自体は第13条の相談窓口で受け付ける）。
6. 見送る場合、本部はその旨と理由を本人に伝え、経緯を記録する。見送りは懲戒ではなく、サポーターとしての活動を妨げない。

**ウェルカム期間満了時の運用：**

- 満了時の個別の通知・連絡は行わない（満了をもって自動的に正式メンバーとなることは、本規程をもって周知とする）。第4項①〜③に該当する場合のみ、本部から本人へ個別に連絡する。応答期限による登録解除は行わない。
- ウェルカム期間中に年度末（3月末）が到来する場合は、再申込（第8条）により、ウェルカム期間の残りを新年度に引き継ぐ（期間は通算する）。

**地域差への対応：**

- 地域の活動量にはグラデーションがあることを前提とし、全地域に同一の組織化を求めない。
- エリアサポーターが不在または活動が立ち上がっていない地域については、他地域のエリアサポーターが個人の意思で活動を手伝うことを歓迎する（新たな組織・チームの立ち上げを求めるものではない）。
- 当該地域の活動はサポーターだけに委ねず、地域が主体的に活動できるようになるまでの一定期間、本部担当者が伴走する。関与の程度は本部の体制・事情に応じて本部が決定する。

### 第7条 エリア体制

エリアサポーターは、党の地域区分に合わせたエリアを基本単位として構成する。当初は次の13エリアとする。

| 東北 | 青森、岩手、秋田、宮城、山形、福島 |
| 北関東 | 埼玉、茨城、栃木、群馬 |
| 山梨 | 山梨 |
| 千葉 | 千葉 |
| 東京 | 東京 |
| 神奈川 | 神奈川 |
| 北陸・信越 | 新潟、富山、石川、福井、長野 |
| 東海 | 静岡、岐阜、愛知、三重 |
| 近畿 | 滋賀、京都、奈良、和歌山、大阪、兵庫 |
| 中国 | 鳥取、島根、岡山、広島、山口 |
| 四国 | 徳島、香川、愛媛、高知 |
| 九州・沖縄 | 福岡、佐賀、長崎、大分、熊本、宮崎、鹿児島、沖縄 |

エリアは、メンバーの所属および活動・連絡の単位である。エリア内に上下関係や代表者は置かず、第3条の役割は各メンバーが等しく担う。

全都道府県はいずれかのエリアに属する。メンバーが少ないエリアは、当面、他地域メンバーの有志による支援（第6条）および本部が支える。

**エリアの独立：** 複数の都道府県からなるエリアのうち、特定の都道府県で3名以上の希望者が集まった場合、本部と協議のうえ、新たなエリアとして独立できる。独立の可否は本部が判断し、既存エリアの運営に支障をきたす恐れがある場合は見送ることができる。見送る場合、本部はその旨と理由を伝え、経緯を記録する（第13条）。独立した都道府県は元のエリアから外れ、1つの都道府県が同時に2つのエリアに所属することはない（メンバー個人が複数エリアを兼任することは制限しない）。

**上位組織は置かない：** 独立したエリアと元のエリアの間、あるいは複数エリア間で情報交換・連携を行うこと自体は自由である。ただし、エリアを束ねる上位の組織階層（地方ブロック等）は設置しない。連携の窓口は、あくまで各エリア単位のまま明確に保つ。

エリアの新設・分割・再編は、活動の立ち上がりに応じて本部が行う。

### 第8条 任期・解散と再結成

**任期・年度**：エリアサポーターの任期は毎年4月1日から翌年3月末日までの1年間とし、毎年3月末をもって体制を解散する。ただし、本規程の施行に伴う最初の任期（2026年度）に限り、**2026年9月14日から2027年3月31日まで**とする。2年目以降（2027年度〜）は本項の原則（4月1日〜翌年3月末日）による。

**再結成（現メンバーの再申込）**：解散後の再結成は、現メンバーが再申込フォームを提出する方式による。本部は提出を受けて登録確認を行い、新年度のメンバーを決定する。

再申込は本人の意思表明であり、第5条の資格要件を満たす限り、本部はこれを拒否しない（再結成は選別の場ではなく、継続意思と要件の確認の場である）。

再申込をしなかった者は、退任の申し出等の手続きなく自然に登録解除となる（懲戒ではなく、以後の再加入を妨げない）。

**途中加入**：第6条による加入は年度途中でも随時可能とする。年度途中の加入者の任期は当該年度の3月末までとする。

**中間棚卸し**：任期の中間に、本部は登録状況の棚卸し（非稼働メンバーへの連絡・継続意思確認。第10-3項）を行う。中間棚卸しでは再申込手続きは求めない。

**人数の調整**：1地域あたりのメンバー数に一律の上限は設けない。ただし人数の増加により運営に支障（連絡系統の混乱、会議の機能不全等）が生じる場合は、次の順で対応する。

1. 役割分担の明確化（テーマ別・エリア別の分担、連絡系統の整理）
2. チームの分割（エリアの細分化等）
3. 上記でも支障が解消しない場合、次回の再結成時に本部が当該地域と協議のうえ定員を設定できる。定員を設ける場合、選定は事前に公表した客観的基準（申込順・抽選等、活動量の多寡によらない基準）によるものとし、特定個人を狙った選別や人気・支持の多寡による選別は行わない。

本部は、組織フェーズの変化（制度改定等）に応じて、年度途中でもエリアサポーターの体制全体を改組・解散できる。この場合、本部は少なくとも2週間前に対象メンバーへ告知し、経過措置を示す。体制の改組・解散は特定個人を対象とした措置としては行わない（個別の退任は第10条による）。

### 第9条 兼職・利益相反の制限

エリアサポーターは、その中立性・補助的役割と相反する立場との兼任を避けるものとし、また、第3項に定める禁止行為を行ってはならない。兼任の制限に該当することが見込まれる場合は速やかに本部へ申告し、本部と対応を協議する。

**兼任を制限する立場の例とその対応：**

- 公職選挙の候補（予定）者。候補（予定）者となった場合は、退任とする（公認・推薦・支援の有無や所属を問わず、無所属での立候補を含む）。選挙終了後、第5条の要件を満たす場合は第6条により再加入できる。
- 他の政党・政治団体において、組織の運営・意思決定に関わる役職に就いている立場
- 党と利益相反する団体の役員等、エリアサポーターとしての公正な活動が困難となる立場

**禁止する行為の例：**

- エリアサポーターの立場を利用した営業・勧誘（宗教・マルチ商法・自己の事業への誘導等）
- 党の資源（広報物・チラシ・物品・予算・データ等）を、私的目的に流用すること
- 党の内部情報の外部への提供

**制限しないもの**：他の政党・政治団体の党員・サポーター・支持者であること自体（第2項に定める役職に就いている場合を除く）、個人としての投票・応援、過去の立候補歴。

本条による退任は懲戒ではなく役割整理であり、退任者はサポーターとしての活動を引き続き歓迎される。事由が解消し第5条の要件を満たす場合は、第6条により再加入できる。ただし第3項の禁止行為に該当する場合は、第10-2項の手続（解任）の対象となる。

### 第10条 退任（退任事由・手続）

**10-1. 退任事由**

次の各号のいずれかに該当する場合、エリアサポーターを退任するものとする。

1. **本人の申し出**：理由を問わず、いつでも可能である。申し出は本部へのSlackで一言伝えれば足りる。本部は申し出を受けて登録を解除し、本人へその旨を確認する。
2. **資格要件の喪失**（第5条各号のいずれかを満たさなくなった場合。第9条の利益相反を含む）
3. **非稼働**（第10-3項の手続による整理）
4. **重大なルール違反**（第10-2項の手続による解任）

**10-2. ルール違反による解任の手続（段階的プロセス）**

解任は、記録可能な具体的行為（第3条4項のDon'tに該当する行為、第4条の越権行為、第9条3項の禁止行為、サポーターガイドライン・アンチハラスメントポリシーその他本部が定めるルールへの違反等）を根拠とする場合に限り行うことができる。違反行為が事後に判明した場合も、記録・確認できる限り本項の手続の対象とする。

違反行為があった場合、本部はまず、必要に応じて事実確認や本人へのヒアリング等を行ったうえで、注意・改善の要請を行う。注意・改善の要請を受けたにもかかわらず同様の行為が繰り返される場合は、本部の合議により解任を決定する。

緊急性が高い場合（法令違反、個人情報の漏洩、党の資源の流用等）は、段階を省略して即時の活動停止（登録一時停止）を行うことができる。

解任の決定・根拠・経緯は本部にて記録し保管する。多数決や署名等、特定メンバーへの人気・支持の多寡を解任の根拠としない。

**10-3. 非稼働メンバーの整理**

- 本部は棚卸し時に、活動が確認できないメンバーへSlackにて連絡する。
- 2週間以内に応答がない場合はリマインドを1回行い、さらに2週間（初回連絡から計4週間）応答がない場合、メンバーリストから削除する（削除は懲戒ではなく登録整理であり、再加入を妨げない）。
- Slackで連絡がつかない場合は、本部が把握している他の連絡手段を1回試みたうえで同様に扱う。

**10-4. 退任時の共通事項**

- 退任・解任・整理のいずれの場合も、サポーターとしての活動は原則として妨げない（第10-1項第4号〔重大なルール違反による解任〕の場合は本部が個別に判断する）。
- 退任後は、エリアサポーターとして保有していたアカウント権限・グループ管理権限等を削除する。

### 第11条 意見収集・コミュニケーションチャネル

他者の行為に関する申告は、匿名掲示ツールではなく第13条の相談窓口へ行うものとする。窓口への申告は記録され、事実確認の対象となる一方、申告者が不利益を受けないことを保証する。匿名の場での真偽不明な告発の拡散は、コミュニティの分断と不要な心理的負担を生むため行わない。

サポーターの個人情報と紐づく意見収集ツールの新規開発・導入は、本部の承認を経て行う（個人情報保護の観点から、有志による独自開発・公開は行わない）。

### 第12条 情報の取り扱い

エリアサポーター間のチャンネル・会議・DM等でやり取りされる、検討中の議論や個人の発言・個人情報・本部からの未公開情報については、発言者や本部の了承なく外部に公開・転載しないよう配慮する。

党のバリューとの整合は、次の切り分けにより担保する。

- **公開するもの**：決定事項、活動報告、確定したルール・方針（本部が適切な形でとりまとめて公開する）
- **非公開とするもの**：検討途中の議論の経過、個人が特定される発言、個人情報、公開により混乱や個人への不利益を招くおそれのある情報
- **除外（守秘義務違反とならないもの）**：
  - 地域活動の運営上必要な範囲での情報共有（イベントの案内・日程調整・活動連絡等、性質上サポーターへの共有が予定されている情報）
  - 第13条の相談窓口への申告・相談
  - 法令に基づき開示が必要な場合
  - 本人の同意を得た本人に関する情報の共有

本条への違反（無許可の外部公開・転載、スクリーンショットの拡散等）は記録可能な具体的行為であり、第10-2項の手続による解任事由となる。

### 第13条 相談窓口・記録

本部に、エリアサポーター・サポーターからの相談窓口を設置する（加入トラブル、ルール違反の申告等）。

窓口への申告は、所定フォームのほか、本部メンバーへのSlack DMでも行うことができる。DMを受けた本部メンバーは、窓口への申告として記録・対応する。

相談者が不利益を受けないことを保証し、報復行為は第10-2項の手続による解任事由とする。

本規程に基づく判断（登録・退任・解任等）は、判断者・日付・根拠を記録し、本部にて保管する。

### 第14条 改定

本規程の改定は組織活動本部が行い、改定内容と適用日を全メンバーへ周知する。

メンバー・サポーターは本部に対し改定の提案を行うことができる。提案は本部が検討し、採否と理由を回答する。
