# リーダーチーム再始動ロードマップ

## この資料の位置づけ

- **目的**: リーダーチーム運営規程の施行〜新体制スタート（9/14）までを、同じ地図を見ながら進められるようにする。「今どこにいて」「何を」「どの順番で」「誰が」決めるのかを揃え、**あわせて「今回は解かない」ことも明示して合意する**。
- **スコープ外にすること自体がこの資料の役割の一つ**。全部やろうとするとキャパシティを超え、9/14に間に合わない。「後で困るが今は割り切る」ことを同じ理解で受け入れるための資料。

参照した一次情報：
- リーダーチーム運営規程（案）
- 現リーダーチームへのAIインタビュー集約レポート（54名分）
- リーダーチームMtgのチャット分析（名称変更・お試し期間・エリア区分・地域戦略に関する討議）
- 確定スケジュール（8/27, 9/9, 9/11, 9/14）
- 名称変更（RCV）・エリア区分・立替払い・再結成の進め方に関する追加決定事項
- 7論点に関する組織活動本部の意思決定（本セッションで確定・一部は検討継続）

## 2. 何を解くか／解かないか

同じ土俵で全部を扱うと収拾がつかないため、次の3つに仕分けて合意する。

### A. 9/14までに答えを出す（新体制のスタート・8/27送付物に必須）

これがないと8/27の案内が送れない、9/14に新体制を開始できない、または新規メンバーの受け入れが初日から止まる論点。大きな方針は決定済みのため、残るのは実装の詰め。

1. **見送り時の通知プロセス**（決定済みの合否基準に基づき、誰が・どう伝えるか・記録の残し方を運用手順に落とす）
2. **8/27フォームの設計**（継続／退任の選択肢、非稼働整理の応答期間変更の反映、Slackに加えLINEを併用するか）
3. **継続意思確認の実務**（リマインド設計・一人一回回答の担保）
4. **RCVの実施準備**（候補名の確定、投票システム・一人一票の担保・通知方法。8/27に実施案内を同送するため、ここがクリティカルパス）
5. **時限的委任ルールの文書化**（選挙期間・大型イベント・緊急時の3場面について、委任の範囲・記録方法・事後報告のフォーマットを具体化）

### B. 9/14の必須条件にはしないが、並行して整える実務

1. **立替払い（道路使用許可）の運用フロー確定**：対象範囲は決定済み。既存の申請フォームを使った申請〜精算までの手順を明文化し、リーダーチームへ周知する
2. **運用ガイド（Q&A）の整備**：非稼働整理の新しい応答期間、クローズド連絡の線引き、連絡経路など（5章バックログの「運用ガイドで決める」群）。9/14までにドラフト、新体制発足後に公開・更新

### C. 今回は着手しない（次の規程改定サイクル・別の意思決定体に委ねる）

明確に「今回は解かない」と決め、その理由とともにメンバーに伝えるべき論点。

| 論点 | 今回扱わない理由 | 対応方針（提案。6章参照） |
|---|---|---|
| エリア14区分そのものの再編 | 区分は確定区分として維持することを決定済み。個別の実情（例：宮城/福井の担当分け）は都度の個別対応で吸収する | ─（決定済みのため対応不要） |
| フェーズ別の地域戦略設計（ながたK氏提起） | 重要な指摘だが、今回のスコープ（規程再始動）より一段上の中期テーマ。持ち帰り、別枠で検討時間を確保する | 提起者本人を含むワーキングセッションを9/14キックオフ後1〜2ヶ月以内に1回開催することを今日確定し、担当者を割り振る |
| 規程本文の抜本的な書き直し（分量・厳格さへの賛否など） | 大枠は据え置き、9/14の運用に支障が出る条文のみ最小限修正する（第6条・第10条の応答期間・運用ルール明確化が中心） | ─（対応不要） |

**この仕分けをそのまま8/27前の合意事項とし、9/11の新体制発表・9/14のキックオフでも「今回決めたこと／次回以降に持ち越すこと」として一言添えられるようにしておく。**これをしないと、アンケートで既に出ている「都合よく運用されているのでは」という不信感（見送り基準の曖昧さ、クローズドな場での決定への懸念）を再燃させるリスクがある。

## 4. 意思決定の型（誰がどう決めるか）

- **お試し期間の合否・本格加入の可否**：デフォルト合格＋客観ゲート（決定済み）。例外協議のみ本部決定＋地域推薦を参考にする
- **名称変更**：全サポーター対象のRCV投票で決定。事前に説明資料（Slack・LINE）＋希望者向け説明会。開票は事前告知した日時・場所で結果発表（配信なし）（決定済み）
- **再結成の進め方**：既存メンバーのフォーム確認を先行 → 9/14キックオフ → 新規募集は随時受付で締め切らない（決定済み）
- **エリア区分**：現行14区分を確定区分として維持し、実情に合わない部分は個別対応で調整する（決定済み）
- **立替払い**：道路使用許可のみ例外的に立替を認める（決定済み）。運用フローの確定はPhase 0〜1で進める
- **「調整・支援役」の実務**：時限的委任ルール（選挙期間・大型イベント・緊急時）で対応（決定済み）
- **インセンティブ・地方支部**：導入しない／設置しない（決定済み）
- **非稼働整理の応答期間**：計4週間への延長を提案中（Phase 0で確定）
- **中長期の組織設計論点（フェーズ別地域戦略設計等）**：この場では決定しない。持ち帰り、検討の場を別途設定することだけを今回決める

## 6. 論点ごとの本部提案（意思決定案）

以下は検討継続中の2論点。**まだ確定ではない提案（叩き台）**。

| 論点 | 提案する意思決定 | 主な根拠 |
|---|---|---|
| 非稼働整理の応答期間（第10-3条） | **計4週間（2週間＋2週間）へ延長。新たな「休止」ステータスは設けない** | 指摘の実態は「本人が忙しい／連絡手段が一時的にない中で、短い期限に気づかず登録解除される」ことへの不満（#7「2週間はあっという間」、#33「海外出張」、#10「4週間ぐらいはあってもいい」）。これは事前の自己申告を前提とする「休止」ステータスでは救えない（不意の多忙・海外出張・トラブルは事前申告できない）。応答期間そのものを伸ばす方がシンプルで運用コストも増えない。長期の予定された休養（病気療養・介護等）が今後も課題として出てくる場合は、その時点で改めて「休止」ステータスの必要性を検討する |
| フェーズ別の地域戦略設計（ながたK氏提起） | Category C継続は妥当。**提起者本人を含むワーキングセッションを9/14キックオフ後1〜2ヶ月以内に1回開催することを今日確定**し、担当者を割り振る | ながたK氏の指摘は「サポーターの党との関わりの深さには段階（認知→登録→参加→深い関与）があり、地域ごとにどの段階に注力すべきか戦略が必要」という組織全体の育成戦略の話で、今回の規程再始動より一段上のテーマ。抽象的な「持ち帰る」で終わらせず、人と日程を割り当てることが公平な扱いになる |

## まとめ：今日合意すべきこと

1. お試し期間の長さ・合否基準・時限的委任・インセンティブなし・支部なし、の5点は決定済みとして1章に反映した
2. 非稼働整理の応答期間（4週間への延長）を今日中に確定する
3. フェーズ別の地域戦略設計は、ワーキングセッションの開催と担当者の割り振りまでを今日決める
4. **Phase 0が最も重い**（規程スライド化・フォーム設計・RCV準備が集中する）。担当と期限を今日割り振って着手する
5. 2章Cの論点は「捨てる」のではなく「今回は持ち越す」と明言し、9/11の発表・9/14のキックオフで誠実に伝える
