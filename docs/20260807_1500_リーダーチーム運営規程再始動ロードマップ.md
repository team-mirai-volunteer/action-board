## この資料の位置づけ

- **目的**: リーダーチーム運営規程の施行〜新体制スタート（9/14）までを、同じ地図を見ながら進められるようにする。「今どこにいて」「何を」「どの順番で」「誰が」決めるのかを揃え、**あわせて「今回は解かない」ことも明示して合意する**。

## 2. 現状の立ち位置

### 決まっていること（動かせない制約・すでに決定済みの方針）

| 項目 | 内容 |
|---|---|
| スケジュール | 上表の通り。8/27・9/9・9/11・9/14は変更不可、それ以前は今回組んだ日程で進める |
| 継続の原則 | 継続を希望し要件（第5条）を満たす現メンバーは全員継続。回答がなければ一旦登録解除（再加入はいつでも歓迎）。ふるい落としの場ではない |
| 再結成の進め方 | 既存メンバーのフォーム意思確認（8/27送付）→ 9/14キックオフ → その後フォームで新規募集を開始。締め切りは設けず随時受け付ける |
| 新規募集の一時停止 | 8/13（全サポーターへのRCV依頼と同時）から9/14（新体制始動・随時募集の再開）まで、リーダーチームの新規募集フォームを一時停止する |
| 名称変更のプロセス | 全サポーター対象のRCV投票で決定。候補名確定→既存リーダーチームへの事前アナウンス→全サポーターへの説明＋投票依頼→投票（8/13〜8/19）→開票（8/20）→発表（8/21）の順で進める。周知はSlack・LINE（配信なし）＋希望者向け説明会 |
| 既存リーダーチームへの事前アナウンス | 全サポーターに説明資料・RCVを展開する前に、既存メンバーへ先に「名称変更の背景・今後の流れ」を伝える（全体の流れの説明を重視。混乱を避けるため） |
| 開票・結果発表 | 開票のライブ配信は行わず、事前に告知した日時・場所で結果を発表する |
| エリア区分 | 現行の14区分を確定区分として維持する（区分自体の見直しは行わない） |
| 立替払い | 道路使用許可の申請費用のみ、例外的に立替を認める（現地でしか支払えないため）。運用フローは準備中だが、申請用フォームは用意済み（[申請フォーム](https://docs.google.com/forms/d/e/1FAIpQLSdzDMQIxEtHqH-iqDN_Ub5D1vBoUTuoQJEcmtPwxpF7dLyZVw/viewform)） |
| お試し期間の長さ | **3ヶ月固定**（期間基準のみ、タスク量基準は採らない） |
| 合否基準 | **デフォルト合格＋最小限の客観ゲート**：①既存メンバーとの顔合わせ1回（定例参加で兼ねてよい）②期間中に第3条Don't／第9条禁止行為に該当する記録可能な違反がないこと。両方満たせば自動承認・通知のみ。本部協議は「地域からの懸念申告」「第5条要件の不備」の2ケースに限定 |
| 「調整・支援役」の実務 | 規程の文言（第1条・第3条）は変更しない。リーダーチームへ権限を委任するのではなく、**本部側に即応窓口を設置**する：①選挙期間（公示日〜投票日）②大型集会・街頭イベント当日 ③災害等緊急時、の3場面では本部が当番制の即応連絡先を用意し、現場で判断が必要な場面はそこへ相談して本部が判断・指示する。本部と連絡が取れない安全上のやむを得ない場合に限り現場対応を認め、事後直ちに本部へ報告する |
| 非稼働整理の応答期間（第10-3条） | 初回連絡から**計4週間（2週間＋2週間）**に延長する。新たな「休止」ステータスは設けない |
| インセンティブ設計 | **導入しない**（本部方針として決定） |
| 地方支部 | **設置しない方針**（本部として決定） |
