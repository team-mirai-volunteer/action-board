# リーダーチーム再始動ロードマップ

## この資料の位置づけ

- **目的**: リーダーチーム運営規程の施行〜新体制スタート（9/14）までを、同じ地図を見ながら進められるようにする。「今どこにいて」「何を」「どの順番で」「誰が」決めるのかを揃え、**あわせて「今回は解かない」ことも明示して合意する**。
- **スコープ外にすること自体がこの資料の役割の一つ**。全部やろうとするとキャパシティを超え、9/14に間に合わない。「後で困るが今は割り切る」ことを同じ理解で受け入れるための資料。

参照した一次情報：
- リーダーチーム運営規程（案）
- 現リーダーチームへのAIインタビュー集約レポート（54名分）
- リーダーチームMtgのチャット分析（名称変更・お試し期間・エリア区分・地域戦略に関する討議）
- 確定スケジュール（8/27, 9/9, 9/11, 9/14）
- 名称変更・エリア区分・立替払いに関する追加決定事項

## 1. 現状の立ち位置

### 決まっていること（動かせない制約・すでに決定済みの方針）

| 項目 | 内容 |
|---|---|
| スケジュール | 8/27 継続意思確認をSlackで案内 → 9/9 フォーム回答締切 → 9/11 新体制発表 → 9/14 新体制スタート（変更不可） |
| 継続の原則 | 継続を希望し要件（第5条）を満たす現メンバーは全員継続。回答がなければ一旦登録解除（再加入はいつでも歓迎）。ふるい落としの場ではない |
| 新規加入 | 新しく入る人には「お試し期間」を設ける。長さ・中身は未決定 |
| 規程の骨格 | 役割定義・エリア14区分・任期/解散再結成・退任手続き・相談窓口などは案として作成済み |

| 立替払い | 道路使用許可の申請費用のみ、例外的に立替を認める（現地でしか支払えないため）。運用フローは準備中だが、申請用フォームは用意済み（[申請フォーム](https://docs.google.com/forms/d/e/1FAIpQLSdzDMQIxEtHqH-iqDN_Ub5D1vBoUTuoQJEcmtPwxpF7dLyZVw/viewform)） |

### 決まっていないこと（本資料が扱う論点）

規程案に対して、AIインタビューとリーダーチームMtgの双方から、繰り返し同じ論点が出ている。まずは全体像として並べる。

| 論点 | 規程案の状態 | 現場からの主な指摘 |
|---|---|---|
| お試し期間の長さ | 一律3ヶ月 | Mtgでは2〜3ヶ月が優勢。「期間 vs タスク量」の二軸あり |
| お試し期間中に何をするか／合否基準 | 「本部が資格要件・行為・役割適合性を踏まえ判断」とだけ規定 | 基準が曖昧だと「本部に都合の良い人だけ残る」という不信感リスクが複数箇所で指摘 |
| 「調整・支援役」と現場実態の乖離 | 権限を持たない補助役と規定 | 選挙時は事実上の指揮・決定が必要になる、との指摘 |
| インセンティブ設計・活動評価 | 規程に記載なし | 「報われないと優秀な人ほど離れる」という懸念 |
| 地方支部・党とサポーターの将来的関係 | 規程に記載なし | 支部設置の有無自体が未表明、という指摘 |
| フェーズ別の地域戦略設計 | 規程に記載なし | 「認知→サポーター化→参加→深い関与」の段階ごとに地域戦略を分解すべき、という提起（ながたK氏） |

名称変更・エリア区分・立替払いは方針が決まったため、この一覧からは外した（1章の「決まっていること」を参照）。残った論点も、**規程の運用を回すために今すぐ答えが要る論点**と、**規程の外側にある組織設計の宿題**が混在している。次章でこれを仕分ける。

## 2. 何を解くか／解かないか

同じ土俵で全部を扱うと収拾がつかないため、次の3つに仕分けて合意する。

### A. 9/14までに答えを出す（新体制のスタートに必須）

これがないと9/14に新体制を発表・開始できない、または新規メンバーの受け入れが初日から止まる論点。

1. **お試し期間の長さと合否基準**（規程案の第6条の運用ルール確定）
2. **お試し期間中に何を「お試しした」とみなすか**（合否基準の透明化。Mtgで出た「オプチャの盛り上げ／定例参加／アクションボードのポイント」等をどこまで正式基準にするか）
3. **見送り（本格加入させない）の判断プロセスと通知の型**（本部決定＋地域推薦を参考、という方向性を運用手順に落とす）
4. **継続意思確認フォームの実務**（通知方法・一人一回投票/回答の担保・リマインド設計）

→ これらは規程案の該当条文（第6条）に直接影響するため、**優先度が最も高い**。

### B. 9/14以降、体制発足と並行して進める（方針は決定済み、実務を整える）

1. **名称変更の説明会運営**：対象・チャネル（全サポーター／Slack・LINE／配信なし）は決定済み。残るのは説明会の日程・参加受付の設計
2. **立替払い（道路使用許可）の運用フロー確定**：対象範囲は決定済み（道路使用許可のみ）。既存の申請フォームを使った申請〜精算までの手順を明文化し、リーダーチームへ周知する

### C. 今回は着手しない（次の規程改定サイクル・別の意思決定体に委ねる）

明確に「今回は解かない」と決め、その理由とともにメンバーに伝えるべき論点。

| 論点 | 今回扱わない理由 |
|---|---|
| インセンティブ設計・予算配分（政党交付金モデルの参照など） | 財務・組織全体の設計マターであり、9/14の体制発足とは切り離して検討すべき規模の論点 |
| 地方支部設置・党とサポーターの関係性の再定義 | 党全体の組織戦略に関わり、組織活動本部だけで完結しない |
| エリア14区分そのものの再編 | 区分は確定区分として維持することを決定済み。個別の実情（例：宮城/福井の担当分け）は都度の個別対応で吸収する |
| フェーズ別の地域戦略設計（ながたK氏提起） | 重要な指摘だが、今回のスコープ（規程再始動）より一段上の中期テーマ。持ち帰り、別枠で検討時間を確保する |
| 規程本文の抜本的な書き直し（分量・厳格さへの賛否など） | 大枠は据え置き、9/14の運用に支障が出る条文のみ最小限修正する（第6条の運用ルール明確化が中心） |

**この仕分けをそのまま8/27前の合意事項とし、9/11の新体制発表時にも「今回決めたこと／次回以降に持ち越すこと」として一言添えられるようにしておく。**これをしないと、アンケートで既に出ている「都合よく運用されているのでは」という不信感（見送り基準の曖昧さ、クローズドな場での決定への懸念）を再燃させるリスクがある。

## 4. 意思決定の型（誰がどう決めるか）

Mtgでの議論を踏まえ、論点ごとに決定の型を揃えておく。

- **お試し期間の合否・本格加入の可否**：本部決定＋地域推薦を参考にする（本部が最終権限を持つが、独断にしない）
- **名称変更**：全サポーター対象に説明資料（Slack・LINE）を送付。配信は行わず、希望者向けに説明会を実施（決定済み）
- **エリア区分**：現行14区分を確定区分として維持し、実情に合わない部分は個別対応で調整する（決定済み）
- **立替払い**：道路使用許可のみ例外的に立替を認める（決定済み）。運用フローの確定はPhase 0〜1で進める
- **中長期の組織設計論点（2章C）**：この場では決定しない。持ち帰り、検討の場を別途設定することだけを今回決める

## 5. オープンな懸念（記録として残す）

現時点で答えが出ていないが、無視すると後で信頼に関わるため、意識しておくべき点：

- 見送り基準・非稼働整理の基準は、明文化しても「運用でどう見えるか」が信頼を左右する。判断の記録（判断者・日付・根拠）は規程第13条の通り必ず残す
- 「クローズドな場で決めない」原則と、実務上のLINE連絡・少人数打合せとの線引きは、規程の文言だけでは解決しない。運用ガイド（Q&A形式）を別途用意した方がよい
- 立替払い（道路使用許可）の運用フローは、対象範囲は決まったが実務手順（申請〜精算のタイミング、緊急時の扱い）はまだ詰まっていない。財務側と早めに接続する
