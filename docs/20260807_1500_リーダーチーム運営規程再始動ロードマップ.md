# リーダーチーム再始動ロードマップ（組織活動本部向け）

## この資料の位置づけ

- **読者**: 組織活動本部（5名）
- **目的**: リーダーチーム運営規程の施行〜新体制スタート（9/14）までを、本部として同じ地図を見ながら進められるようにする。「今どこにいて」「何を」「どの順番で」「誰が」決めるのかを揃え、**あわせて「今回は解かない」ことも明示して合意する**。
- **スコープ外にすること自体がこの資料の役割の一つ**。全部やろうとすると本部のキャパシティを超え、9/14に間に合わない。「後で困るが今は割り切る」ことを本部全員が同じ理解で受け入れるための資料。

参照した一次情報：
- リーダーチーム運営規程（案）
- 現リーダーチームへのAIインタビュー集約レポート（54名分）
- リーダーチームMtgのチャット分析（名称変更・お試し期間・エリア区分・地域戦略に関する討議）
- 確定スケジュール（8/27, 9/9, 9/11, 9/14）

## 1. 現状の立ち位置

### 決まっていること（動かせない制約）

| 項目 | 内容 |
|---|---|
| スケジュール | 8/27 継続意思確認をSlackで案内 → 9/9 フォーム回答締切 → 9/11 新体制発表 → 9/14 新体制スタート（変更不可） |
| 継続の原則 | 継続を希望し要件（第5条）を満たす現メンバーは全員継続。回答がなければ一旦登録解除（再加入はいつでも歓迎）。ふるい落としの場ではない |
| 新規加入 | 新しく入る人には「お試し期間」を設ける。長さ・中身は未決定 |
| 規程の骨格 | 役割定義・エリア14区分・任期/解散再結成・退任手続き・相談窓口などは案として作成済み |

### 決まっていないこと（本資料が扱う論点）

規程案に対して、AIインタビューとリーダーチームMtgの双方から、繰り返し同じ論点が出ている。まずは全体像として並べる。

| 論点 | 規程案の状態 | 現場からの主な指摘 |
|---|---|---|
| お試し期間の長さ | 一律3ヶ月 | Mtgでは2〜3ヶ月が優勢。「期間 vs タスク量」の二軸あり |
| お試し期間中に何をするか／合否基準 | 「本部が資格要件・行為・役割適合性を踏まえ判断」とだけ規定 | 基準が曖昧だと「本部に都合の良い人だけ残る」という不信感リスクが複数箇所で指摘 |
| 名称変更（RCV）の対象範囲 | 規程外の別テーマ | Mtgでは「リーダーチーム限定」より「全サポーター対象＋事前説明配信」が優勢。通知方法・投票システムの実装可否は未確認 |
| エリア区分（14区分） | 確定区分として明記 | 北陸信越・福井など、区分が実態に合わない声が複数。現状は個別対応で運用中 |
| 立替払い原則（原則不可） | 本部が支払う／建て替え不可と明記 | 道路使用許可・会場費など、現場で不可避的に立替が発生するとの指摘多数。規程と実務が矛盾 |
| 「調整・支援役」と現場実態の乖離 | 権限を持たない補助役と規定 | 選挙時は事実上の指揮・決定が必要になる、との指摘 |
| インセンティブ設計・活動評価 | 規程に記載なし | 「報われないと優秀な人ほど離れる」という懸念 |
| 地方支部・党とサポーターの将来的関係 | 規程に記載なし | 支部設置の有無自体が未表明、という指摘 |
| フェーズ別の地域戦略設計 | 規程に記載なし | 「認知→サポーター化→参加→深い関与」の段階ごとに地域戦略を分解すべき、という提起（ながたK氏） |

この一覧を見ると、**規程の運用を回すために今すぐ答えが要る論点**と、**規程の外側にある組織設計の宿題**が混在している。次章でこれを仕分ける。

## 2. 何を解くか／解かないか

同じ土俵で全部を扱うと収拾がつかないため、次の3つに仕分けて合意する。

### A. 9/14までに答えを出す（新体制のスタートに必須）

これがないと9/14に新体制を発表・開始できない、または新規メンバーの受け入れが初日から止まる論点。

1. **お試し期間の長さと合否基準**（規程案の第6条の運用ルール確定）
2. **お試し期間中に何を「お試しした」とみなすか**（合否基準の透明化。Mtgで出た「オプチャの盛り上げ／定例参加／アクションボードのポイント」等をどこまで正式基準にするか）
3. **見送り（本格加入させない）の判断プロセスと通知の型**（本部決定＋地域推薦を参考、という方向性を運用手順に落とす）
4. **継続意思確認フォームの実務**（通知方法・一人一回投票/回答の担保・リマインド設計）
5. **エリア区分の運用方針**（区分自体の再設計はしないが、「合わない場合は個別相談で対応する」という運用ルールを明文化し、9/14時点で言えるようにする）

→ これらは規程案の該当条文（第6条・第7条）に直接影響するため、**優先度が最も高い**。

### B. 9/14以降、体制発足と並行して進める（急ぐが9/14の必須条件ではない）

1. **名称変更（RCV）の実施設計**：対象範囲は「全サポーター＋事前説明配信」で方向性は出ているが、通知方法・投票システムの技術的な準備状況の確認が残っている。新体制の名称が決まっていなくても9/14はスタートできる（附則にも「新名称は別途決定」と明記済み）。**新体制スタートのブロッカーにしない。**
2. **立替払い原則の実務ルール整備**：道路使用許可・会場費など、緊急性は高いが「規程の条文をどう直すか」は財務・経理側との調整が要る。9/14までに条文を変えることはしないが、**運用上の暫定対応（誰にいつまでに相談するか）は本部内で早めに共有する。**

### C. 今回は着手しない（次の規程改定サイクル・別の意思決定体に委ねる）

明確に「今回は解かない」と決め、その理由とともにメンバーに伝えるべき論点。

| 論点 | 今回扱わない理由 |
|---|---|
| インセンティブ設計・予算配分（政党交付金モデルの参照など） | 財務・組織全体の設計マターであり、9/14の体制発足とは切り離して検討すべき規模の論点 |
| 地方支部設置・党とサポーターの関係性の再定義 | 党全体の組織戦略に関わり、組織活動本部だけで完結しない |
| エリア14区分の全体再編 | 個別対応（例：宮城/福井の担当分け）で当面の不満は吸収できている。全体再編は次回の任期区切り（第8条の再結成タイミング）で検討する方が影響範囲が扱いやすい |
| フェーズ別の地域戦略設計（ながたK氏提起） | 重要な指摘だが、今回のスコープ（規程再始動）より一段上の中期テーマ。本部として持ち帰り、別枠で検討時間を確保する |
| 規程本文の抜本的な書き直し（分量・厳格さへの賛否など） | 大枠は据え置き、9/14の運用に支障が出る条文のみ最小限修正する（第6条・第7条の運用ルール明確化が中心） |

**この仕分けをそのまま8/27前の本部内合意事項とし、9/11の新体制発表時にも「今回決めたこと／次回以降に持ち越すこと」として一言添えられるようにしておく。**これをしないと、アンケートで既に出ている「本部にとって都合よく運用されているのでは」という不信感（見送り基準の曖昧さ、クローズドな場での決定への懸念）を再燃させるリスクがある。

## 4. 意思決定の型（誰がどう決めるか）

Mtgでの議論を踏まえ、論点ごとに決定の型を揃えておく。

- **お試し期間の合否・本格加入の可否**：本部決定＋地域推薦を参考にする（本部が最終権限を持つが、独断にしない）
- **名称変更**：全サポーター対象のRCV（投票）で決定。事前に説明配信を行う
- **エリアの個別対応**：本部窓口が個別相談ベースで対応（全体ルール改定ではない）
- **中長期の組織設計論点（2章C）**：この場では決定しない。持ち帰り、検討の場を別途設定することだけを今回決める

## 5. 本部としてのオープンな懸念（記録として残す）

現時点で答えが出ていないが、無視すると後で本部の信頼に関わるため、意識しておくべき点：

- 見送り基準・非稼働整理の基準は、明文化しても「運用でどう見えるか」が信頼を左右する。判断の記録（判断者・日付・根拠）は規程第13条の通り必ず残す
- 「クローズドな場で決めない」原則と、実務上のLINE連絡・少人数打合せとの線引きは、規程の文言だけでは解決しない。運用ガイド（Q&A形式）を別途用意した方がよい
- 立替払い原則は、次の規程改定を待たずに実務対応（例：本部担当者が現地手続きに同行する、緊急時のみ例外運用を明文化する等）を先行させる余地がないか、財務側と早めに接続する
