# リーダーチーム再始動ロードマップ

## この資料の位置づけ

- **目的**: リーダーチーム運営規程の施行〜新体制スタート（9/14）までを、同じ地図を見ながら進められるようにする。「今どこにいて」「何を」「どの順番で」「誰が」決めるのかを揃え、**あわせて「今回は解かない」ことも明示して合意する**。
- **スコープ外にすること自体がこの資料の役割の一つ**。全部やろうとするとキャパシティを超え、9/14に間に合わない。「後で困るが今は割り切る」ことを同じ理解で受け入れるための資料。フェーズ別の地域戦略設計（サポーターの育成戦略）のような、リーダーチームの再始動そのものとは別の組織全体テーマは、**この資料の対象外**として扱う。

## 2. 何を解くか／解かないか

大きな方針はほぼ決定済み。残るのは実装の詰めと、8/27告知の粒度の1点。

### A. 8/27までに答えを出す（RCV完了・送付物に必須）

RCVの完了と8/27送付物の準備が最優先。これが遅れると新名称の発表タイミングそのものが守れない。

1. **RCV候補名の確定**（今週中。物理的な最優先事項）
2. **RCV投票システム・説明資料の準備**（配信なし、対象は全サポーター）
3. **RCV投票の実施・開票**（目安8/13〜8/19。8/27の8日以上前に完了）
4. **8/27告知の説明粒度の決定**（6章の提案を踏まえて確定）
5. **見送り時の通知プロセス**（決定済みの合否基準に基づき、誰が・どう伝えるか・記録の残し方を運用手順に落とす）
6. **8/27フォームの設計**（継続／退任の選択肢、応答期間変更の反映、LINE併用の可否）
7. **継続意思確認の実務**（リマインド設計・一人一回回答の担保）
8. **時限的委任ルールの文書化**（選挙期間・大型イベント・緊急時の3場面について、委任の範囲・記録方法・事後報告のフォーマットを具体化）

### B. 9/14の必須条件にはしないが、並行して整える実務

1. **立替払い（道路使用許可）の運用フロー確定**：対象範囲は決定済み。既存の申請フォームを使った申請〜精算までの手順を明文化し、リーダーチームへ周知する
2. **運用ガイド（Q&A）の整備**：非稼働整理の新しい応答期間、クローズド連絡の線引き、連絡経路など（5章バックログの「運用ガイドで決める」群）。9/14までにドラフト、新体制発足後に公開・更新

### C. 今回は着手しない（次の規程改定サイクル・別の意思決定体に委ねる）

| 論点 | 今回扱わない理由 |
|---|---|
| エリア14区分そのものの再編 | 区分は確定区分として維持することを決定済み。個別の実情（例：宮城/福井の担当分け）は都度の個別対応で吸収する |
| 規程本文の抜本的な書き直し（分量・厳格さへの賛否など） | 大枠は据え置き、9/14の運用に支障が出る条文のみ最小限修正する（第6条・第10条の応答期間が中心） |

**フェーズ別の地域戦略設計（ながたK氏提起）は、この資料の対象外とする。** リーダーチームの再始動ではなく、サポーター全体の育成戦略という別テーマのため、本ロードマップでは扱わない（対応するかどうか・どこで扱うかは別途）。

**この仕分けをそのまま合意事項とし、9/11の新体制発表・9/14のキックオフでも「今回決めたこと／次回以降に持ち越すこと」として一言添えられるようにしておく。**

## 4. 意思決定の型（誰がどう決めるか）

- **お試し期間の合否・本格加入の可否**：デフォルト合格＋客観ゲート（決定済み）。例外協議のみ本部決定＋地域推薦を参考にする
- **名称変更**：全サポーター対象のRCV投票で決定。8/27より1週間以上前に完了させる（決定済み）
- **8/27の全体告知**：実施すること自体は決定済み。説明の粒度は6章の提案を踏まえて本部で確定する
- **再結成の進め方**：既存メンバーのフォーム確認を先行 → 9/14キックオフ → 新規募集は随時受付で締め切らない（決定済み）
- **エリア区分**：現行14区分を確定区分として維持し、実情に合わない部分は個別対応で調整する（決定済み）
- **立替払い**：道路使用許可のみ例外的に立替を認める（決定済み）。運用フローの確定はPhase 0〜1で進める
- **「調整・支援役」の実務**：時限的委任ルール（選挙期間・大型イベント・緊急時）で対応（決定済み）
- **インセンティブ・地方支部**：導入しない／設置しない（決定済み）
- **非稼働整理の応答期間**：計4週間へ延長（決定済み）
